# 파이프라인 검증용 테스트 앱

실제 앱을 올리기 전에 **OIDC → ECR → SSM 배포** 경로만 검증하기 위한 최소 구성.

복잡한 앱으로 처음 파이프라인을 뚫으면 실패했을 때 원인이 빌드 문제인지 권한 문제인지
가려내기 어렵다. 이 앱은 의존성이 없고 수 초 만에 빌드되므로 파이프라인 자체만 남는다.

## 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 3000번 포트에서 텍스트를 반환하는 표준 라이브러리 HTTP 서버 |
| `Dockerfile` | `python:3.12-alpine` 기반. `GIT_SHA`를 빌드 인자로 받아 환경변수로 심는다 |

`sha=` 값이 push한 커밋과 일치하면 **새 이미지가 실제로 배포된 것**이다.
이게 확인 안 되면 예전 이미지가 그대로 돌고 있는 것이고, 배포가 성공한 것처럼 보여도 실패다.

## 검증이 끝나면

파이프라인이 확인된 뒤에는 이 앱을 지우고 실제 앱으로 교체한다.
`deploy.yml`과 `docker-compose.yml`은 그대로 재사용한다.
