# 델타 탐색 (상하좌우 이웃 확인)

2차원 격자에서 특정 칸 `(i, j)`의 **상하좌우 이웃 칸**을 확인해야 하는 문제가 자주 나온다. 매번 `i+1`, `i-1`, `j+1`, `j-1`을 따로 적는 대신, 이동량을 배열로 미리 정의해두고 반복문으로 돌리는 방법을 **델타 탐색**이라 부른다.

```python
di = [0, 0, 1, -1]   # 오른쪽, 왼쪽, 아래, 위로 이동할 때 i가 변하는 양
dj = [1, -1, 0, 0]   # 오른쪽, 왼쪽, 아래, 위로 이동할 때 j가 변하는 양

for d in range(4):
    ni = i + di[d]
    nj = j + dj[d]
    print(ni, nj, mat[ni][nj])
```

`di[d]`와 `dj[d]`를 같은 인덱스 `d`로 짝지어 두면 "네 방향 중 하나"를 표현할 수 있다.

## 경계 체크가 필요한 이유

`(i, j)`가 격자의 가장자리에 있으면 `ni`나 `nj`가 범위를 벗어나 `IndexError`가 난다. 이웃을 확인하기 전에 항상 그리드 안에 있는지 검사해야 한다.

```python
n, m = 5, 5

if 0 <= ni < n and 0 <= nj < m:
    # 그리드 범위 안에 있을 때만 안전하게 접근
    ...
```

## 활용 예 — 값 사이의 인접 관계 세기

"격자에서 값이 2인 칸과 상하좌우로 맞닿은 1의 개수를 구하라" 같은 문제는 다음 패턴으로 푼다.

```python
count = 0
for i in range(n):
    for j in range(m):
        if lst[i][j] == 2:
            for d in range(4):
                ni, nj = i + di[d], j + dj[d]
                if 0 <= ni < n and 0 <= nj < m:
                    if lst[ni][nj] == 1:
                        count += 1
print(count)
```

- 어떤 값을 기준으로 이웃을 찾을지(1을 기준으로 2를 찾을지, 2를 기준으로 1을 찾을지)에 따라 코드가 더 단순해질 수 있다.
- "이웃 중 하나만 찾으면 더 볼 필요 없는" 경우엔 `break`로 중복 탐색을 줄인다.
- 방문한 칸을 다시 세지 않으려면 확인 후 값을 바꿔(`lst[ni][nj] = 0`) 표시해두는 방법도 있다.
