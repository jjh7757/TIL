# 정렬(Sort)

## `.sort()` vs `sorted()`

| | 대상 | 반환값 |
|---|---|---|
| `리스트.sort()` | 원본 리스트를 그 자리에서 변경 | `None` |
| `sorted(리스트)` | 원본은 그대로 두고 새 리스트 생성 | 정렬된 새 리스트 |

```python
lst1 = [2, 1, 6, 8, 3]
result1 = lst1.sort()
print(result1, lst1)   # None [1, 2, 3, 6, 8] — 원본이 바뀜

lst2 = [2, 1, 6, 8, 3]
result2 = sorted(lst2)
print(result2, lst2)   # [1, 2, 3, 6, 8] [2, 1, 6, 8, 3] — 원본 유지
```

## 카운팅 정렬 — 값의 범위를 알 때

정렬할 값이 **정해진 범위**(예: 1~10) 안에 있다는 걸 안다면, 값을 직접 비교하는 대신 각 값이 몇 번 등장했는지 세어서 순서대로 꺼내는 방법을 쓸 수 있다.

```python
lst = [1, 3, 2, 5, 4, 6, 8, 7, 9, 10, 3, 5, 3, 5, 1]

counting_lst = [0] * 11   # index 0~10, 값의 등장 횟수를 셀 공간

for num in lst:
    counting_lst[num] += 1

sorted_lst = []
for i in range(1, 11):
    for _ in range(counting_lst[i]):   # i가 등장한 횟수만큼
        sorted_lst.append(i)
```

값 자체를 인덱스로 쓰기 때문에 비교 연산 없이 정렬할 수 있어 빠르지만, **범위를 모르는 임의의 값**에는 쓸 수 없다는 한계가 있다.

## 버블 정렬 — 인접한 두 값을 계속 비교

인접한 두 값을 비교해 큰 값을 오른쪽으로 보내는 것을 반복한다. 한 바퀴가 끝나면 그 구간에서 가장 큰 값이 맨 뒤에 확정되므로, 다음 바퀴는 확정된 만큼 범위를 줄인다.

```python
lst = [6, 5, 2, 3, 8, 7, 4, 1, 0]

for j in range(1, len(lst)):          # 바퀴 수
    for i in range(len(lst) - j):     # 바퀴가 진행될수록 비교 범위가 줄어듦
        if lst[i] > lst[i + 1]:
            lst[i], lst[i + 1] = lst[i + 1], lst[i]
```

## 선택 정렬 — 가장 작은 값을 앞에서부터 확정

정렬된 결과는 "맨 앞이 가장 작고, 그다음이 그다음으로 작다"는 점에 착안한다. 남은 구간에서 가장 작은 값의 인덱스를 찾아 구간의 맨 앞과 자리를 바꾸는 것을 반복한다.

```python
lst = [6, 5, 4, 2, 8, 7, 3, 1, 0]

for start in range(len(lst) - 1):
    min_index = start
    for i in range(start, len(lst)):
        if lst[i] < lst[min_index]:
            min_index = i
    lst[start], lst[min_index] = lst[min_index], lst[start]
```

버블 정렬은 "인접한 것끼리 계속 맞바꾸며" 큰 값을 뒤로 밀어내고, 선택 정렬은 "가장 작은 것을 찾아서" 앞자리를 하나씩 채워나간다는 점에서 접근 방식이 반대다.
