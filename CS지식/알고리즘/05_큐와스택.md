# 큐와 스택(Queue & Stack)

둘 다 데이터를 순서대로 쌓아두는 자료구조지만, **어디서 꺼내는가**가 다르다.

| | 삽입 | 삭제 |
|---|---|---|
| 큐(Queue) | 한쪽 끝 | **반대쪽** 끝 (선입선출, FIFO) |
| 스택(Stack) | 한쪽 끝 | **같은쪽** 끝 (후입선출, LIFO) |

## `collections.deque`

파이썬 리스트로도 흉내낼 수 있지만, `list.insert(0, x)`나 `list.pop(0)`처럼 **맨 앞**을 다루는 연산은 나머지 원소를 전부 한 칸씩 밀어야 해서 `O(n)`이다. `deque`(double-ended queue)는 양쪽 끝 모두 `O(1)`로 넣고 뺄 수 있게 만들어진 자료구조다.

```python
from collections import deque

q = deque([1, 2, 3, 4, 5])

# 오른쪽 기준
q.append(6)      # [1, 2, 3, 4, 5, 6]
el = q.pop()      # el = 6, q = [1, 2, 3, 4, 5]

# 왼쪽 기준
q.appendleft(6)   # [6, 1, 2, 3, 4, 5]
el = q.popleft()  # el = 6, q = [1, 2, 3, 4, 5]
```

`append`+`pop`만 쓰면 스택처럼, `append`+`popleft`만 쓰면 큐처럼 동작한다.

## 실전 문제 1 — 올바른 괄호 (스택)

> 괄호 문자열이 짝이 맞게 열리고 닫히는지 판별한다. ([프로그래머스 12909](https://school.programmers.co.kr/learn/courses/30/lessons/12909))

괄호가 `()` 한 종류뿐이라면 카운팅만으로 충분하다 — 여는 괄호는 +1, 닫는 괄호는 -1, 도중에 값이 음수가 되면 즉시 `False`(닫는 게 먼저 나온 경우), 끝까지 값이 0이면 `True`.

```python
def solution(s):
    value = 0
    for char in s:
        if char == '(':
            value += 1
        elif char == ')':
            value -= 1
        if value < 0:      # 닫히는 게 더 많은 시점을 즉시 감지
            return False
    return value == 0
```

괄호 종류가 `()`, `{}`, `[]`처럼 여러 개로 늘어나면 카운팅만으로는 짝이 맞는지 구분할 수 없다 — 이때 스택이 필요하다. 여는 괄호를 만나면 스택에 쌓고, 닫는 괄호를 만나면 스택 맨 위(가장 최근에 연 괄호)와 짝이 맞는지 확인한다.

```python
from collections import deque

def solution(s):
    stack = deque()
    open_blanket = {'(', '{', '['}          # in 검사는 set이 O(1), list는 O(n)
    blanket_mapping = {')': '(', '}': '{', ']': '['}

    for char in s:
        if char in open_blanket:
            stack.append(char)
        elif char in blanket_mapping:
            if not stack:                          # 닫히는 게 더 많은 경우
                return False
            if stack[-1] != blanket_mapping[char]:  # 짝이 맞지 않는 경우
                return False
            stack.pop()

    return not stack   # 열린 채로 남아있으면 False
```

## 실전 문제 2 — 다리를 지나는 트럭 (큐)

> 다리를 건널 수 있는 무게 제한이 있을 때, 트럭들이 모두 다리를 건너는 데 걸리는 시간을 구한다. ([프로그래머스 42583](https://school.programmers.co.kr/learn/courses/30/lessons/42583))

다리 위 상태를 **길이가 `bridge_length`인 큐**로 표현하는 것이 핵심이다. 큐의 각 칸은 "그 위치에 있는 트럭의 무게"를 의미하고(빈 칸은 0), 1초마다 큐를 한 칸씩 미는 것을 `popleft`(맨 앞 트럭이 다리를 건넘) + `append`(새 트럭 진입 또는 빈 칸)로 표현한다.

```python
from collections import deque

def solution(bridge_length, weight, truck_weights):
    bridge = deque([0] * bridge_length)   # 다리 위 상태
    bridge_weight = 0                     # 다리 위 트럭들의 총 무게
    ready_truck_index = 0
    time = 0

    while bridge_weight > 0 or ready_truck_index < len(truck_weights):
        bridge_weight -= bridge.popleft()   # 맨 앞 트럭이 다리를 건너감

        if (ready_truck_index < len(truck_weights)
                and bridge_weight + truck_weights[ready_truck_index] <= weight):
            truck = truck_weights[ready_truck_index]
            bridge.append(truck)
            bridge_weight += truck
            ready_truck_index += 1
        else:
            bridge.append(0)   # 못 들어가면 빈 칸으로 자리만 채움

        time += 1

    return time
```

무게 제한 때문에 다음 트럭을 못 태우는 틱에도 `time`은 흘러야 하므로, 못 들어갈 땐 `0`을 채워 넣어 다리의 길이(칸 수)를 그대로 유지하는 점이 포인트다.
