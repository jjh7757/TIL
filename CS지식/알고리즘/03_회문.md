# 회문(Palindrome)

**회문**은 거꾸로 읽어도 원래와 같은 문자열이다. (`수박이박수`, `abcdcba`)

## 방법 1 — 슬라이싱으로 뒤집기

```python
def is_palindrome(word):
    return word == word[::-1]
```

가장 간결하지만, 뒤집힌 새 문자열을 하나 더 만든다.

## 방법 2 — 반복문으로 뒤집기

인덱스를 거꾸로 순회하며 한 글자씩 이어 붙여도 같은 결과를 만들 수 있다.

```python
def is_palindrome(word):
    reversed_word = ""
    for index in range(len(word) - 1, -1, -1):   # range(start, end, step)
        reversed_word += word[index]
    return word == reversed_word
```

`for char in word:`로 순회하면서 매번 앞에 붙여도(`reversed_word = char + reversed_word`) 같은 효과를 낼 수 있다.

## 방법 3 — 뒤집지 않고 절반만 비교

문자열 전체를 뒤집을 필요 없이, 양 끝에서부터 안쪽으로 대응되는 글자만 비교하면 된다. 앞뒤를 맞비교하므로 **절반만** 확인해도 충분하다.

```python
def is_palindrome(word):
    for start in range(len(word) // 2):
        end = len(word) - start - 1
        if word[start] != word[end]:
            return False
    return True
```

## 방법 4 — 투 포인터(Two Pointer)

왼쪽 인덱스와 오른쪽 인덱스를 각각 양 끝에 두고, 서로 만날 때까지 좁혀오면서 비교한다. 방법 3과 같은 아이디어를 `while`로 표현한 것이다.

```python
def is_palindrome(word):
    left, right = 0, len(word) - 1
    while left < right:
        if word[left] != word[right]:
            return False
        left += 1
        right -= 1
    return True
```

문자열을 새로 만들지 않고 다르면 즉시 `False`로 끝낼 수 있어(early return), 네 방법 중 가장 효율적이다.
