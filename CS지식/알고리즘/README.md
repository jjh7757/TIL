# 알고리즘

알고리즘 실습 노트북(2차원 배열부터 나선형 배열까지)을 주제별로 간단히 정리한 문서입니다.

1. [2차원 배열](01_2차원배열.md) — `mat[i][j]` 인덱싱, 행/열 우선 순회, n×m 배열 생성, 0으로 채운 grid 만들 때의 참조 함정
2. [델타 탐색](02_델타탐색.md) — 상하좌우 이웃 탐색을 위한 `di`/`dj` 배열, 경계 체크, 인접 관계 세기 예제
3. [회문](03_회문.md) — 슬라이싱·반복문·절반 비교·투 포인터로 회문 판별하는 네 가지 방법
4. [정렬](04_정렬.md) — `.sort()` vs `sorted()`, 카운팅 정렬, 버블 정렬, 선택 정렬
5. [큐와 스택](05_큐와스택.md) — `collections.deque`, 올바른 괄호(스택), 다리를 지나는 트럭(큐) 풀이
6. [나선형 배열](06_나선형배열.md) — 방향 벡터 순환으로 시계방향 나선 채우기, 범위/중복 체크
