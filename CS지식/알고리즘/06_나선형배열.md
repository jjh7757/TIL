# 나선형 배열 채우기(Spiral Matrix)

n×n 2차원 배열을 왼쪽 위부터 시계방향 나선형으로 1부터 n²까지 채우는 문제.

```
 1  2  3  4  5
16 17 18 19  6
15 24 25 20  7
14 23 22 21  8
13 12 11 10  9
```

## 1. 빈 grid 준비 — 참조 함정 주의

`n×n` 크기를 미리 만들어두고 값만 채워 넣는 방식이 편하다. 이때 `[[0]*n for _ in range(n)]`처럼 **각 행을 매번 새로 생성**해야 한다. ([2차원 배열](01_2차원배열.md)에서 다룬 것처럼) `[[0]*n]*n`으로 만들면 n개의 행이 전부 같은 리스트를 참조하게 되어, 한 칸만 바꿔도 모든 행이 같이 바뀌는 함정에 빠진다.

```python
snail = [[0]*n for _ in range(n)]
```

## 2. 방향 벡터로 진행 방향 표현

상하좌우 이동을 `if`로 매번 분기하는 대신, [델타 탐색](02_델타탐색.md)에서처럼 방향을 배열로 미리 정의해두고 인덱스로 선택한다.

```python
#     우  하  좌  상
di = [0, 1, 0, -1]
dj = [1, 0, -1, 0]

d = 0   # 현재 방향 (di[d], dj[d])
```

## 3. 핵심 — 벽에 부딪히거나 이미 채워진 칸을 만나면 방향 전환

바로 옆 칸으로 이동하기 전에, **이동할 후보 좌표 `(ni, nj)`를 먼저 계산**해서 조건을 검사한다. 직접 `i`, `j`를 바꾼 뒤 되돌리는 방식보다 다루기 쉽다.

나선이 안쪽으로 감겨 들어갈 때는 "grid 범위를 벗어났는가"뿐 아니라 "이미 숫자가 채워진 칸인가"도 함께 확인해야 한다. 범위 체크만 하면 안쪽 라인을 돌 때 이미 채운 칸을 다시 밟고 지나가 버린다.

```python
for num in range(1, n**2 + 1):
    snail[i][j] = num

    ni = i + di[d]
    nj = j + dj[d]

    # grid를 벗어났거나, 이미 값이 채워진 칸이면 방향 전환
    if not (0 <= ni < n and 0 <= nj < n) or snail[ni][nj]:
        d = (d + 1) % 4                # 4방향을 순환하도록 나머지 연산
        ni = i + di[d]
        nj = j + dj[d]

    i, j = ni, nj
```

`d += 1`만 하면 네 번째 방향 전환에서 `d`가 4가 되어 `di[4]`가 `IndexError`를 낸다. `d = (d + 1) % 4`로 방향 인덱스를 0~3 사이로 순환시킨다.
