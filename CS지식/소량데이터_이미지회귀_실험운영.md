# 소량 데이터 이미지 회귀: 실험을 운영하는 법

이미지 수백 장으로 연속값을 예측하는 회귀 문제를 하루 동안 붙잡고 배운 것들이다. 검증 틀(저장된 폴드·OOF·기준선)과 누수 방지는 [교차검증과 데이터 누수](교차검증과데이터누수.md)에서 정리했고, 이 글은 그 틀 위에서 실험을 어떻게 고르고 판단했는지를 다룬다. 모델 이름보다 **"무엇을 믿고 무엇을 버릴지 정하는 방법"**이 더 중요했다.

```
사전학습 모델로 특징 추출 (가중치 고정)
→ 층·입력·전처리 바꿔 가며 선형 회귀로 비교
→ 서로 다른 성분을 섞어 앙상블
→ 오차 분석으로 "어디서 틀리는지" 확인 → 다음 실험 결정
```

## 1. 사전학습 특징 + 선형 회귀가 강한 이유

데이터가 수백 장이면 큰 모델을 처음부터 학습하거나 통째로 미세조정하면 금방 과적합한다. 대신 **사전학습 모델의 가중치를 고정하고 특징만 뽑은 뒤, Ridge 같은 선형 회귀**를 얹으면 안정적인 기준이 된다(linear probe).

| 방식 | 학습하는 파라미터 | 데이터 수백 장일 때 |
|---|---|---|
| 처음부터 학습 | 전부 | 거의 항상 과적합 |
| 전체 미세조정 | 전부 (초기값만 사전학습) | 빠르게 과적합, 설정에 민감 |
| LoRA 등 부분 미세조정 | 일부 저차원 행렬 | 가능하지만 이득이 작을 수 있음 |
| **고정 특징 + 선형 회귀** | 회귀 계수만 | **안정적, 빠름, 기준으로 좋음** |

### 마지막 층이 최선이 아닐 수 있다

분류용으로 학습된 모델의 마지막 층은 "이게 무엇인가"에 맞춰져 있다. 질감이나 명암 분포처럼 **저수준 정보가 중요한 문제에서는 중간 층이 더 좋을 수 있다.** 처음에 마지막 몇 층만 비교하고 넘어갔다가, 나중에 **모든 층을 처음부터 끝까지 스윕**해 보니 최적 층이 전혀 다른 곳에 있었다.

- 교훈: 층 선택은 일부만 보지 말고 **전부 스윕**한다. 특징을 한 번 뽑아 두면 회귀는 몇 초면 끝난다.
- 같은 층이 **다른 조건(입력 크기 등)에서도 반복해서 최적**으로 나오면, 우연이 아니라 실제 패턴일 가능성이 높다.

## 2. 증강은 "라벨을 바꾸지 않는 변환"만

회전·반전을 8가지(0·90·180·270도 × 좌우반전)로 적용해 **학습 데이터로도 쓰고, 예측할 때도 8개 예측을 평균(TTA)**했다. 효과가 꽤 컸다. 단 전제가 있다.

- **방향이 라벨과 무관하다는 걸 데이터로 먼저 확인**해야 한다. 방향 지표와 라벨의 상관이 0에 가까운지 본다.
- 같은 이미지에서 나온 변형 8개는 **CV 분할에서 반드시 같은 쪽**에 둔다. 안 그러면 검증 데이터의 "쌍둥이"가 학습에 들어가 점수가 부풀려진다.

### 리사이즈: "무작위 배율"과 "일괄 배율"은 다르다

크기 정보가 중요한 문제라서 처음에는 리사이즈를 아예 금지했다. 그런데 따져 보니 두 가지는 다르다.

| 변환 | 이미지 간 상대 크기 | 판단 |
|---|---|---|
| 무작위 배율 증강 (이미지마다 다른 배율) | 깨짐 | 금지 |
| **모든 이미지를 같은 배율로 확대** | 보존 | 허용 |

일괄 2배 확대는 패치 기반 모델(ViT)의 토큰 해상도를 높여 준다. 단독 점수는 비슷했지만, 원본 입력과 **다른 오차를 내서 앙상블에 도움**이 됐다.

## 3. 앙상블: 단독 점수보다 "다르게 틀리는가"

| 상황 | 결과 |
|---|---|
| 성분끼리 예측 상관 0.97 이상 | 섞어도 거의 변화 없음 |
| 단독은 기준보다 조금 나쁘지만 상관이 낮음 (0.93) | **섞으면 확실히 좋아짐** |
| 상관은 낮지만 단독이 너무 약함 | 섞으면 오히려 나빠짐 |

- 미세조정 모델이 단독으로는 선형 회귀보다 조금 나빴는데, **일부 비중만 섞으니 개선**됐다. 단독 점수만 보고 버렸으면 놓쳤을 것이다.
- 반대로 아주 다른 표현(시각 단어 히스토그램)은 상관이 낮았지만 단독이 약해서 앙상블에 보탬이 안 됐다.
- 같은 모델의 **시드만 바꾼 앙상블**은 test 예측 상관이 0.99 이상이라 앙상블 효과가 거의 없었다. 대신 **검증 신뢰도**(여러 폴드 분할에서 일관되게 좋은가)를 높이는 데 의미가 있었다.

## 4. 미세조정 head가 학습되지 않던 이유

미세조정이 초반 여러 에포크 동안 전혀 나아지지 않는 현상이 반복됐다. 원인은 단순했다.

- 사전학습 모델의 풀링 특징은 **이미지 간 차이가 아주 작았다**(채널별 표준편차가 1e-3 단위).
- 회귀 head를 0으로 초기화하면, 의미 있는 크기의 가중치까지 자라는 데 오래 걸린다.

해결은 두 가지였다.

1. 특징을 **학습 데이터의 평균·표준편차로 표준화**한다 (선형 회귀의 StandardScaler와 같은 역할).
2. head를 **고정 특징으로 푼 Ridge 해로 초기화**한다. 학습이 "이미 검증된 선형 모델"에서 출발하고, 미세조정은 그 위를 다듬기만 한다(linear probe → fine-tune).

```python
F0 = feats(train_images)                        # 고정 모델로 뽑은 특징
mu, sd = F0.mean(0), F0.std(0) + 1e-6
ridge = RidgeCV(alphas=np.logspace(0, 5, 30)).fit((F0 - mu) / sd, y_std)
head.weight.copy_(torch.tensor(ridge.coef_)[None])  # Ridge 해에서 출발
head.bias.fill_(ridge.intercept_)
```

이렇게 하니 첫 에포크부터 선형 모델 수준에서 출발했다. **이전에 "미세조정은 효과 없다"고 결론 냈던 실험들도 사실 이 문제 때문이었을 수 있다** — 실패의 원인이 방법인지 구현인지 구분하는 게 중요하다.

## 5. 실험 운영 원칙

### 채택 기준은 결과를 보기 전에 정한다

- "새 성분을 같은 비중으로 넣고, CV가 0.03 이상 좋아지면 채택"처럼 **규칙을 먼저 적고** 실험한다.
- OOF 점수를 보고 비중(10%? 30%?)을 고르면, 그 점수는 **낙관적으로 부풀려진다.** 미리 정한 기본값(예: 25%)을 쓴다.
- 미세조정 곡선을 보고 "에포크를 줄이자"고 설정을 바꿨다면, **다른 폴드 분할(다른 시드)로 다시 평가**해야 공정하다.

### 오차 분석은 "다중비교 기준선"과 함께

잔차(정답 - 예측)와 수천 개 지표의 상관을 보면 우연히 큰 값이 몇 개는 나온다. 지표 m개를 볼 때 우연으로 나올 수 있는 최대 상관은 대략 이렇다.

```python
from scipy.stats import norm
thr = norm.ppf(1 - 0.025 / m) / np.sqrt(n - 3)   # 본페로니 보정, n = 표본 수
```

- 예를 들어 지표 100개, 표본 1,000개면 |ρ| 0.11 정도까지는 우연으로 설명된다.
- 상관보다 확실한 판단: **잔차를 그 지표로 학습해 보정했을 때 CV가 실제로 좋아지는가.** 좋아지지 않으면 놓친 신호가 아니다.

### 구간별 오차를 본다

전체 점수가 같아도 **어디서 틀리는지**는 다르다. 화질(노이즈·선명도) 사분위별로 오차를 나눠 보니, 라벨과 무관한 화질 열화가 심한 이미지에서 오차가 눈에 띄게 컸다. 그래서 **입력 단계에서 이미지마다 추정한 노이즈 크기에 비례한 평활**을 적용했더니 그 구간이 개선됐다.

반면 회귀 단계에서 노이즈를 더한 복사본으로 학습하는 방법은 효과가 없었다. **특징을 뽑는 순간 이미 정보가 손실되면, 회귀 단계에서 되살릴 수 없다.**

### CV를 기준으로, 리더보드는 확인용으로

리더보드 점수는 test의 일부(수백 장)로만 계산돼 표본 오차가 크다. CV 변화와 리더보드 변화의 **방향이 매번 일치하는지**를 기록해 두면, CV를 믿어도 되는지 판단할 수 있다.

## 6. 장시간 작업 운영 (Windows)

| 문제 | 해결 |
|---|---|
| 도구의 백그라운드 실행이 2시간 제한으로 끊김 | `Start-Process`로 세션과 분리된 독립 프로세스 실행 |
| 몇 시간짜리 추출 중 노트북이 절전 진입 | 작업 프로세스 안에서 `SetThreadExecutionState`로 그 프로세스가 사는 동안만 절전 방지 (시스템 설정 변경 없음) |
| CPU로 큰 모델 미세조정이 비현실적 | 무료 코랩 T4로 실험만 옮김. 데이터는 본인 드라이브에 **비공개**로 |
| 실험 코드가 여러 스크립트에 흩어짐 | `run_all.py` 하나로 특징 추출 → 학습 → 예측. 저장된 특징으로 다시 돌려 **결과가 비트 단위로 같은지** 검증 |

```python
# 이 프로세스가 살아 있는 동안만 절전 방지
import ctypes
ctypes.windll.kernel32.SetThreadExecutionState(0x80000000 | 0x00000001)  # ES_CONTINUOUS | ES_SYSTEM_REQUIRED
```

## 정리

- **고정 특징 + 선형 회귀**를 기준으로 두고, 층은 전부 스윕한다.
- 증강은 라벨 불변이 데이터로 확인된 것만, 같은 이미지의 변형은 같은 폴드에.
- 앙상블은 **"다르게 틀리는"** 성분을 찾는 일이다.
- 미세조정이 안 될 땐 방법보다 **초기화와 특징 스케일**부터 의심한다.
- 채택 기준은 미리, 오차 분석은 다중비교 기준선과 함께, 판단은 CV로.
