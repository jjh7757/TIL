# 웹 서비스 구조

수업 중 손글씨 판서를 정리한 내용입니다.

## 전체 흐름

```
Client(Web Browser) ──http(요청/응답)──▶ ┌─ Server ────────────┐
                     ◀──────────────────  FE(동적 웹페이지) ◀─API─▶ BE
                                          └─────────────────────┘
```

1. **Client (Web Browser)**: 사용자가 웹페이지를 요청하는 주체
2. **Server**: FE와 BE를 함께 담고 있는 서버
   - **FE**: 클라이언트의 요청에 맞춰 **동적 웹페이지**를 만들어 HTML로 응답하는 영역
   - **BE**: FE의 요청을 받아 실제 데이터 처리를 담당하는 영역
3. **Client ↔ FE**: **HTTP(요청/응답)** 로 통신 — 브라우저가 요청을 보내면 FE가 웹페이지(HTML)로 응답
4. **FE ↔ BE**: **API** 로 통신 — FE가 필요한 데이터를 BE에 요청하고 응답받음

## 정리
브라우저(Client)가 HTTP로 요청을 보내면 서버 안의 FE가 이를 받아, 필요하면 API를 통해 BE와 데이터를 주고받은 뒤 동적 웹페이지(HTML)를 만들어 브라우저에 응답한다.
