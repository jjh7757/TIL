# 소프트웨어 종류

Software는 실행 환경 기준으로 크게 세 가지 종류로 나뉜다.

```text
Software
 ├─ 웹 (Web)
 ├─ 모바일 (App)
 └─ 데스크탑 (윈도우)
```

## 웹 (Web)
브라우저에서 실행되는 소프트웨어. 역할에 따라 두 영역으로 나뉜다.

- **FE (Frontend)**: 사용자가 보는 화면, 브라우저에서 동작
- **BE (Backend)**: 서버에서 데이터 처리, FE의 요청에 응답

FE와 BE는 요청/응답으로 서로 순환하며 상호작용한다.

## 모바일 (App)
스마트폰에서 실행되는 소프트웨어. 플랫폼별로 나뉜다.

- **Android**: 안드로이드 네이티브 앱
- **iOS**: 애플 네이티브 앱
- **BE (Backend)**: 앱의 데이터를 처리하는 서버

### 크로스플랫폼
Android/iOS를 각각 따로 개발하지 않고, 하나의 코드로 양쪽 앱을 만드는 방식.

- **Flutter**
- **React Native (RN)**

네이티브 대비 개발 속도는 빠르지만, 플랫폼 고유 기능 접근이나 성능 면에서는 네이티브보다 제약이 있을 수 있다.

## 데스크탑 (윈도우)
PC(윈도우)에서 실행되는 소프트웨어.

- **유틸**: 사용자가 직접 쓰는 유틸리티 프로그램
- **BO (Back Office)**: 내부 운영/관리용 프로그램

## 정리
| 구분 | 세부 종류 | 비고 |
|------|-----------|------|
| 웹 | FE / BE | 브라우저 기반 |
| 모바일 | Android / iOS / BE | 크로스플랫폼(Flutter, React Native)으로 통합 개발 가능 |
| 데스크탑 | 유틸 / BO | 윈도우 기준 |
