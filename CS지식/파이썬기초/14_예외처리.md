# 예외 처리(Exception Handling)

오류(error)는 프로그램에서 발생하는 문제를 넓게 부르는 말이고, 예외(exception)는 그중 실행 중에 발생하며 파이썬이 감지하고 처리할 수 있는 오류 상황이다. 예외 처리는 이런 상황이 생겨도 프로그램이 비정상 종료되지 않도록, 실행 흐름을 제어해 적절히 처리하거나 복구하는 방법이다.

## 기본 구조 — try/except

`try` 블록에 예외가 발생할 수 있는 코드를 두고, 예외가 실제로 발생하면 `except` 블록이 대신 실행된다.

```python
try:
    result = 10 / 0
    print(result)
except:
    print("예외가 발생하였습니다.")
```

## 특정 예외만 처리하기

`except` 뒤에 예외 클래스를 명시하면 그 예외만 선택적으로 처리한다.

```python
try:
    numbers = [1, 2, 3]
    print(numbers[5])   # 인덱스 범위 초과
except IndexError:
    print("인덱스 범위를 초과하였습니다.")
```

예외 종류를 지정하지 않는 `except:`(bare except)는 의도하지 않은 다른 오류까지 전부 삼켜버려 디버깅을 어렵게 만들 수 있다. 어떤 예외가 발생할 수 있는지 알고 있다면 명시하는 편이 낫다.

## 여러 예외를 각각 처리하기

`except` 블록을 여러 개 이어 붙이면 예외 종류별로 다른 처리를 할 수 있다.

```python
try:
    value = int(input())
    result = 10 / value
    print(result)
except ValueError:
    print("형변환에 실패하였습니다.")
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다.")
```

## 예외 객체 참조 — as

`as` 키워드로 발생한 예외 객체를 변수에 담으면, 시스템이 전달하는 실제 오류 메시지를 확인할 수 있다.

```python
try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(e)   # division by zero
```

## else / finally — 성공/종료 시점 제어

`else`는 `try` 블록에서 예외가 **발생하지 않았을 때만** 실행되고, `finally`는 예외 발생·처리 여부와 무관하게 **항상 마지막에** 실행된다.

```python
def divide_data(input_value):
    try:
        number = int(input_value)
        calculation = 100 / number
    except ValueError:
        print("숫자 형태의 문자가 아닙니다.")
    except ZeroDivisionError:
        print("0으로 나눌 수 없습니다.")
    else:
        print(f"연산 결과는 {calculation} 입니다.")
    finally:
        print("데이터 처리를 완료했습니다.")

divide_data("20")   # 연산 결과는 5.0 입니다. / 데이터 처리를 완료했습니다.
divide_data("0")    # 0으로 나눌 수 없습니다. / 데이터 처리를 완료했습니다.
```

`finally`는 성공하든 실패하든 반드시 정리해야 하는 작업(파일 닫기, 연결 종료 등)에 적합하다.

## 예외 강제 발생 — raise

`raise`로 특정 조건에서 의도적으로 예외를 일으켜 프로그램 흐름을 중단시킬 수 있다.

```python
def check_age(age):
    if age < 0:
        raise ValueError("나이는 음수일 수 없습니다.")
    return age

try:
    check_age(-5)
except ValueError as e:
    print(e)   # 나이는 음수일 수 없습니다.
```

## 사용자 정의 예외

기본 `Exception` 클래스를 상속받으면 상황에 맞는 이름의 예외를 직접 정의할 수 있다.

```python
class MyCustomError(Exception):
    def __init__(self, message):
        self.message = message

try:
    raise MyCustomError("사용자 정의 오류가 발생했습니다.")
except MyCustomError as e:
    print(e.message)
```

기본 제공 예외(`ValueError`, `IndexError` 등)로 상황을 정확히 표현하기 어려울 때, 사용자 정의 예외로 코드의 의도를 더 명확하게 드러낼 수 있다.
