# 추상 클래스와 다형성

## 다형성(Polymorphism) — 같은 메서드 이름, 다른 동작

[클래스 상속](16_클래스상속.md)에서 오버라이딩으로 같은 이름의 메서드를 자식마다 다르게 구현할 수 있다는 것을 봤다. 다형성은 이 성질을 이용해, 실제 타입이 무엇인지 신경 쓰지 않고 여러 객체를 **같은 방식으로** 다루는 것이다.

```python
class Dog:
    def speak(self):
        print("멍멍")

class Cat:
    def speak(self):
        print("야옹")

animals = [Dog(), Cat()]
for animal in animals:
    animal.speak()   # 각자 실제 타입에 맞는 speak가 호출됨
```

`Dog`와 `Cat`은 상속 관계가 없는데도, 같은 이름(`speak`)의 메서드만 가지고 있으면 이렇게 동일한 코드로 다룰 수 있다 — 이를 **덕타이핑(duck typing)**이라 부른다("오리처럼 걷고 오리처럼 운다면 오리로 취급한다").

상속 관계가 있는 경우도 원리는 같다.

```python
class Person:
    def __init__(self, name):
        self.name = name
    def perform_role(self):
        pass

class Student(Person):
    def perform_role(self):
        return f"학생 {self.name}은 학습을 수행합니다."

class Teacher(Person):
    def perform_role(self):
        return f"교사 {self.name}은 강의를 수행합니다."

people = [Student("김철수"), Teacher("이영희")]
for person in people:
    print(person.perform_role())   # 리스트를 순회할 때는 Person으로만 다루지만, 실제 호출은 각자의 구현으로 감
```

## 추상 클래스(ABC)로 "반드시 구현해야 함"을 강제하기

`perform_role`처럼 부모가 빈 메서드(`pass`)만 정의해두면, 자식이 구현을 깜빡해도 에러 없이 조용히 `None`만 반환된다. `abc` 모듈의 `ABC`와 `@abstractmethod`를 쓰면 "이 메서드는 자식이 반드시 구현해야 한다"는 규칙을 파이썬이 직접 강제하게 만들 수 있다.

```python
from abc import ABC, abstractmethod

class Person(ABC):
    @abstractmethod
    def work(self):
        pass

class Student(Person):
    def work(self):
        print("학습을 진행합니다.")

class Teacher(Person):
    pass   # work()를 구현하지 않음

Student().work()   # 정상 동작
Teacher()           # TypeError: Can't instantiate abstract class Teacher without an implementation for abstract method 'work'
```

추상 메서드가 하나라도 구현되지 않은 클래스는 **인스턴스를 만드는 시점에 바로 에러**가 나서, "구현을 깜빡한 채로 조용히 실행되는" 상황을 막아준다. 도형 넓이 계산처럼 "종류는 다양하지만 반드시 계산 방법을 가져야 하는" 구조에 잘 맞는다.

```python
class Shape(ABC):
    @abstractmethod
    def get_area(self):
        pass

class Square(Shape):
    def __init__(self, side):
        self.side = side
    def get_area(self):
        return self.side ** 2

class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius
    def get_area(self):
        return 3.14 * (self.radius ** 2)

for shape in [Square(10), Circle(10)]:
    print(shape.get_area())   # 각 도형에 맞는 계산식이 호출됨 — 다형성
```
