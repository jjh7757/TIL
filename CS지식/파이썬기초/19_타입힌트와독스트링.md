# 타입 힌트(Type Hinting)와 독스트링

## 타입 힌트란

타입 힌트는 변수·매개변수·반환값에 기대하는 자료형을 명시하는 문법이다. 실행 시점에 강제되지는 않지만, 편집기 자동완성과 정적 분석 도구가 타입 오류를 미리 잡아내는 데 도움을 준다.

```python
user_count: int = 10
user_name: str = "관리자"

def calculate_total(price: int, count: int) -> int:
    return price * count
```

## 컨테이너와 합집합 타입

```python
numbers: list[int] = [1, 2, 3]
user_scores: dict[str, int] = {"kim": 90, "lee": 80}

# 여러 타입 중 하나를 허용 — 파이썬 3.10+ (이전 버전은 typing.Union 사용)
def process_id(user_id: int | str) -> None:
    print(f"아이디 확인: {user_id}")

def find_user_name(user_id: int) -> str | None:
    return "관리자" if user_id == 1 else None
```

## 클래스를 타입 힌트로 — 다형성과 함께 쓰기

클래스 이름을 타입 힌트로 쓰면 "이 클래스 또는 그 하위 클래스의 인스턴스"를 받는다는 의도를 드러낼 수 있다. [합성](18_합성과의존성주입.md)에서 다룬, 부모 타입으로 여러 구현체를 갈아 끼우는 패턴과 자연스럽게 맞물린다.

```python
class Notifier:
    def send(self, message: str) -> None:
        raise NotImplementedError

class EmailNotifier(Notifier):
    def send(self, message: str) -> None:
        print(f"[이메일] {message}")

class OrderService:
    def __init__(self, notifier: Notifier):   # Notifier 또는 그 자식이면 무엇이든 OK
        self.notifier = notifier

    def complete_order(self, order_id: int) -> None:
        self.notifier.send(f"주문 {order_id}번이 완료되었습니다.")
```

다만 타입 힌트는 **강제성이 없다** — `Notifier`와 무관한 다른 클래스의 인스턴스를 넘겨도 파이썬은 실행을 막지 않는다. 실수를 예방하는 문서화·도구 지원 장치이지, 런타임 유효성 검사가 아니다.

## 독스트링(Docstring)

함수·클래스·모듈의 첫 줄에 세 겹 큰따옴표로 작성하는 문자열로, 그 대상의 의도와 사용법을 설명한다. `#` 주석과 달리 런타임에 `__doc__` 속성으로 남아 `help()`로도 조회할 수 있다.

```python
def calculate_area(radius: float) -> float:
    """원의 반지름을 입력받아 면적을 계산하여 반환함.

    Args:
        radius: 원의 반지름.
    Returns:
        계산된 원의 면적.
    """
    import math
    return math.pi * (radius ** 2)

print(calculate_area.__doc__)   # 독스트링 내용이 그대로 출력됨
help(calculate_area)             # 함수 시그니처 + 독스트링을 함께 보여줌
```
