# 연산자(Operators)

## 산술 연산자

| 연산자 | 설명 | 연산자 | 설명 |
|:---:|---|:---:|---|
| `+` | 덧셈 | `-` | 뺄셈 |
| `*` | 곱셈 | `/` | 나눗셈 (결과는 항상 `float`) |
| `//` | 몫 | `%` | 나머지 |
| `**` | 제곱 | | |

> 0으로 나누면(`/`, `//`, `%` 모두) `ZeroDivisionError`가 발생한다.

## 복합 연산자

산술 연산 후 같은 변수에 재할당할 때 축약해서 쓴다.

| 복합 연산자 | 의미 | 복합 연산자 | 의미 |
|:---:|---|:---:|---|
| `a += b` | `a = a + b` | `a -= b` | `a = a - b` |
| `a *= b` | `a = a * b` | `a /= b` | `a = a / b` |
| `a //= b` | `a = a // b` | `a %= b` | `a = a % b` |
| `a **= b` | `a = a ** b` | | |

> 오른쪽에 연산식이 오면 그 식이 먼저 계산된다. `a -= b + 3`은 `a = a - (b + 3)`으로 계산됨.

## 비교 연산자

| 연산자 | 의미 | 연산자 | 의미 |
|:---:|---|:---:|---|
| `<` | 미만 | `<=` | 이하 |
| `>` | 초과 | `>=` | 이상 |
| `==` | 같다 | `!=` | 같지 않다 |

숫자뿐 아니라 문자열도 비교 가능하다 (`"python" == "PYTHON"`은 대소문자를 구별하므로 `False`).

## 논리 연산자

| 연산자 | 설명 |
|:---:|---|
| `a and b` | 둘 다 `True`면 `True` |
| `a or b` | 하나라도 `True`면 `True` |
| `not a` | `a`의 반대 |

불린형이 아닌 값도 [자료형](02_자료형.md)의 `bool()` 판정 기준에 따라 참/거짓으로 평가되어 논리 연산에 쓰일 수 있다 (`not 0` → `True`, `not "python"` → `False`).

## 연산자 우선순위 (숫자가 낮을수록 먼저 계산)

| 우선순위 | 연산자 | 설명 |
|:---:|---|---|
| 1 | `**` | 거듭제곱 |
| 2 | `+x`, `-x`, `~x` | 단항 연산자 |
| 3 | `*`, `/`, `//`, `%` | 곱셈·나눗셈·몫·나머지 |
| 4 | `+`, `-` | 덧셈·뺄셈 |
| 5~8 | `<<` `>>` `&` `^` `|` | 비트 연산 |
| 9 | `<` `<=` `>` `>=` `==` `!=` `in` `is` | 비교·멤버십·동일성 |
| 10~12 | `not` → `and` → `or` | 논리 연산 |
| 13 | `if ... else` | 조건 표현식 |
| 14 | `lambda` | 람다 표현식 |
