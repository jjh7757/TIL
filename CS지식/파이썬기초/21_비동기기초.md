# 비동기(Async) 기초

## 동기 vs 비동기

네트워크 응답, 데이터베이스 조회, 파일 읽기처럼 **결과가 올 때까지 기다려야 하는 작업**이 많다. 기다리는 동안 프로그램이 뭘 하느냐가 동기와 비동기의 차이다.

| 방식 | 기다리는 동안 | 흐름 |
|---|---|---|
| 동기 | 프로그램도 함께 멈춰서 기다림 | A 시작 → A 완료 → B 시작 → B 완료 |
| 비동기 | 다른 작업을 진행함 | A 요청 → 기다리는 동안 B 요청 → 끝난 것부터 처리 |

비동기는 **계산 자체가 오래 걸리는 작업**이 아니라, **결과를 기다리는 시간이 긴 입출력 작업**(API 요청, DB 조회, 파일 입출력)을 여러 개 동시에 처리할 때 유리하다.

## 이벤트 루프와 코루틴

Python에서는 **이벤트 루프**가 실행할 코루틴들을 관리한다. 코루틴이 `await`에서 기다리기 시작하면, 이벤트 루프는 그동안 실행 가능한 다른 코루틴으로 넘어간다. 기다리던 결과가 도착하면 멈췄던 지점부터 이어서 실행한다.

```python
async def async_work(name: str, seconds: int) -> str:
    print(name, "시작")
    await asyncio.sleep(seconds)
    print(name, "완료")
    return f"{name} 결과"
```

`async def`로 정의한 함수는 **코루틴 함수**다. 호출해도 바로 결과가 나오지 않고 **코루틴 객체**가 만들어지며, `await`해야 실행되고 결과를 받는다.

> ⚠️ **`async`를 썼다고 자동으로 동시 실행되는 게 아니다.** 코루틴을 하나씩 `await`하면 [일반 동기 코드처럼 순서대로](#순차-실행--하나씩-await) 실행된다. 동시에 실행하려면 아래 `asyncio.gather()`가 필요하다.

## 순차 실행 — 하나씩 `await`

```python
results = []
for name in ["작업 A", "작업 B", "작업 C"]:
    result = await async_work(name, 1)   # 앞 작업이 끝나야 다음 작업 시작 — 동기와 동일하게 3초 소요
    results.append(result)
```

## `asyncio.gather()` — 여러 코루틴을 함께 실행

```python
results = await asyncio.gather(
    async_work("작업 A", 1),
    async_work("작업 B", 2),
    async_work("작업 C", 1),
)
# 가장 오래 걸리는 작업(2초) 기준으로 끝남 — 순차 실행(4초)보다 빠름
```

`gather()`에 코루틴을 여러 개 전달하면 한 작업이 기다리는 동안 다른 작업도 진행된다. **반환되는 결과 순서는 끝난 순서가 아니라 `gather()`에 전달한 순서**다.

## 실전 — 여러 API 요청을 동시에 보내기

`httpx`는 `requests`와 사용법이 비슷하면서 비동기 요청을 지원하는 HTTP 클라이언트다.

```python
import httpx, asyncio, time

async def get_post(client: httpx.AsyncClient, post_id: int) -> dict:
    response = await client.get(f"https://jsonplaceholder.typicode.com/posts/{post_id}")
    response.raise_for_status()
    return response.json()

post_ids = [1, 2, 3, 4, 5]

async with httpx.AsyncClient(timeout=10.0) as http_client:
    start = time.perf_counter()
    posts = await asyncio.gather(*(get_post(http_client, pid) for pid in post_ids))
    print(f"걸린 시간: {time.perf_counter() - start:.2f}초")   # 5번 순차 요청보다 훨씬 빠름
```

`*(...)`는 [추가 문법 모음](20_추가문법모음.md#패킹과-언패킹)에서 본 언패킹이다 — 제너레이터가 만든 코루틴들을 `gather()`의 여러 인자로 풀어서 전달한다.

## Jupyter Notebook vs `.py` 파일

Jupyter Notebook(Colab 포함)은 이미 이벤트 루프가 돌고 있어서 셀에 `await`를 바로 쓸 수 있다. 반면 일반 `.py` 파일의 최상위 코드에서는 `await`를 바로 쓸 수 없고, `asyncio.run()`으로 이벤트 루프를 직접 시작해야 한다.

```python
async def main():
    results = await asyncio.gather(
        async_work("작업 A", 1),
        async_work("작업 B", 1),
    )
    print(results)

if __name__ == "__main__":
    asyncio.run(main())
```

Notebook 안에서 `asyncio.run()`을 호출하면 이미 실행 중인 이벤트 루프와 충돌할 수 있으므로, Notebook에서는 `asyncio.run()` 없이 `await`만 쓴다.
