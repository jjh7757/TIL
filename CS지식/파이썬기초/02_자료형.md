# 자료형(Data Types)

자료형은 데이터가 어떤 형태인지를 뜻한다. 처리할 자료의 형태를 알아야 올바른 연산 결과를 얻을 수 있다.

## 숫자형

| 종류 | 설명 | 예시 |
|---|---|---|
| 정수형(`int`) | 양의 정수, 음의 정수, 0 | `100`, `0`, `-25` |
| 실수형(`float`) | 소수점이 포함된 숫자 | `1.2`, `-3.56`, `4.0` |

> `4.0`은 정수 `4`와 같아 보이지만 소수점이 있으므로 `float`이다.

## 문자열(String)

작은따옴표(`'`) 또는 큰따옴표(`"`)로 감싸 표기한다.

- 공백(`' '`)과 빈 문자열(`''`)도 하나의 문자열로 취급된다.
- 따옴표 종류를 섞어 쓰면(`'Hello"`) `SyntaxError` 발생.
- 같은 종류의 따옴표를 중첩하면 에러. 서로 다른 따옴표로 감싸거나(`"'작은따옴표'"`) 이스케이프 시퀀스를 쓴다.

**이스케이프 시퀀스**

| 시퀀스 | 설명 |
|:---:|---|
| `\'` | 작은따옴표 표현 |
| `\"` | 큰따옴표 표현 |
| `\\` | 백슬래시 표현 |
| `\n` | 줄바꿈 |
| `\t` | 탭 |

> 숫자 `123`과 문자열 `'123'`은 겉보기엔 같아도 자료형이 다르며, 할 수 있는 연산이 다르다.

## 불린형(Boolean)

참(`True`)과 거짓(`False`) 두 값만 가진다.

## 명시적 형변환(Typecasting)

| 함수 | 역할 | 주의 |
|---|---|---|
| `int()` | 문자열(정수 형태)·실수 → 정수 | 실수 → 정수는 소수점 버림(`int(-1.5)` → `-1`). `int('1.5')`처럼 실수 형태 문자열은 바로 변환 불가(`ValueError`) |
| `float()` | 문자열(실수 형태)·정수 → 실수 | 계산식 형태 문자열(`'3/5'`)은 변환 불가 |
| `str()` | 값 → 문자열 | |
| `bool()` | 값 → 참/거짓 | 아래 표 참고 |

**`bool()` 판정 기준** — 파이썬은 데이터의 유무로 참/거짓을 평가한다.

| 값 | 결과 | 설명 |
|---|:---:|---|
| `0`, `0.0` | `False` | 숫자 0은 거짓 |
| `''` (빈 문자열) | `False` | 내용 없으면 거짓 |
| `[]` (빈 리스트) | `False` | 비어있으면 거짓 |
| `1`, `-1`, `1.5` | `True` | 0 이외 숫자는 참 |
| `'Hello'` | `True` | 내용 있으면 참 |
| `[1, 2, 3]` | `True` | 요소 있으면 참 |
