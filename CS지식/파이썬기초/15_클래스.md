# 클래스(Class)

클래스는 관련 있는 데이터(속성)와 동작(메서드)을 하나로 묶어 정의하는 설계도다. 클래스로 찍어낸 실제 데이터 뭉치를 인스턴스(객체)라고 부른다.

## 기본 구조 — `__init__`과 `self`

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print(f"나의 이름은 {self.name}, 나이는 {self.age}")

p1 = Person("김철수", 25)
p1.introduce()
```

`__init__`은 인스턴스가 생성될 때 자동으로 호출되는 생성자다. 첫 번째 매개변수 `self`는 "지금 만들어지는(또는 메서드를 호출한) 인스턴스 자신"을 가리키며, 메서드 안에서 인스턴스별 속성(`self.name`)에 접근하려면 반드시 필요하다.

## 인스턴스 변수 vs 클래스 변수

클래스 변수는 `__init__` 밖, 클래스 몸체에 바로 선언하며 **모든 인스턴스가 값을 공유**한다.

```python
class Person:
    population = 0   # 클래스 변수

    def __init__(self, name):
        self.name = name
        Person.population += 1

p1 = Person("철수")
p2 = Person("영희")
print(Person.population)   # 2
print(p1.population)       # 2 — 인스턴스에서도 클래스 변수를 읽을 수 있다
```

주의: `p1.population = 100`처럼 인스턴스에 값을 **대입**하면, `Person`의 클래스 변수를 바꾸는 게 아니라 `p1`에만 존재하는 새 **인스턴스 변수**가 생겨 클래스 변수를 가린다(shadowing).

```python
p1.population = 100
print(p1.population)      # 100 — p1만의 값
print(p2.population)      # 2   — 그대로, 영향 없음
print(Person.population)  # 2   — 그대로
```

[스코프](13_스코프.md)에서 함수 안에 `value = ...`로 대입하면 같은 이름의 새 local 변수가 생기는 것과 같은 원리다 — **대입은 항상 새 이름을 만드는 쪽으로 동작**한다.

## 매직 메서드 — 내장 함수·연산자와 연결하기

`__`로 시작해서 `__`로 끝나는 메서드는 파이썬의 내장 함수나 연산자가 호출될 때 자동으로 실행된다.

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __str__(self):
        return f"제목: {self.title}"       # print(book), str(book)

    def __len__(self):
        return self.pages                   # len(book)

    def __gt__(self, other):
        return self.pages > other.pages     # book > other_book

book = Book("오딧세이아", 799)
short_book = Book("동화", 100)

print(book)               # 제목: 오딧세이아   (__str__)
print(len(book))          # 799               (__len__)
print(book > short_book)  # True              (__gt__)
```

정의해두지 않으면 `print(book)`은 `<__main__.Book object at 0x...>`처럼 의미 없는 값을 출력하고, `len(book)`이나 `book > other`는 애초에 에러가 난다.

## `@property` — 메서드를 변수처럼 쓰기

```python
class Person:
    def __init__(self, age):
        self._age = age

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        if value < 0:
            print("나이는 음수일 수 없습니다.")
        else:
            self._age = value

p = Person(20)
p.age = -5   # setter가 가로채서 거부
p.age = 25
print(p.age)   # 괄호 없이 변수처럼 접근하지만 실제로는 getter 메서드가 호출됨
```

내부 값(`_age`, 관례상 `_`를 붙여 "직접 건드리지 말라"는 뜻)을 그대로 노출하지 않고, `age`라는 이름으로 읽고 쓸 때마다 로직(유효성 검사 등)을 끼워 넣을 수 있다.

## `@classmethod` — 인스턴스가 아닌 클래스에 접근하는 메서드

```python
class Person:
    population = 0

    def __init__(self, name):
        self.name = name
        Person.population += 1

    @classmethod
    def get_population(cls):   # cls: 이 메서드가 속한 클래스 자신
        return cls.population

Person("사용자1")
Person("사용자2")
print(Person.get_population())   # 2 — 인스턴스 없이 클래스 이름으로 바로 호출
```

일반 메서드의 첫 매개변수가 인스턴스(`self`)인 것처럼, `classmethod`의 첫 매개변수는 클래스 자신(`cls`)이다. 인스턴스 하나에 묶이지 않는 로직(클래스 변수 조회 등)에 적합하다.

## 메서드에 데코레이터 적용하기

함수를 감싸 공통 로직(로깅 등)을 끼워 넣는 [데코레이터](11_함수.md)는 클래스 메서드에도 그대로 적용할 수 있다. 이때 감싸는 함수는 `self`까지 함께 받아 그대로 전달해야 한다.

```python
def trace_log(func):
    def wrapper(self, *args, **kwargs):
        print(f"실행 기록: {func.__name__} 메서드가 호출되었습니다.")
        result = func(self, *args, **kwargs)
        print(f"실행 기록: {func.__name__} 메서드가 끝났습니다.")
        return result
    return wrapper

class Person:
    def __init__(self, name):
        self.name = name

    @trace_log
    def walk(self):
        print(f"{self.name}이 걷고 있습니다.")

Person("홍길동").walk()
```
