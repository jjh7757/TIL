# 변수(Variables)

변수란 **데이터의 값을 저장하는 상자**입니다. `변수 이름 = 값` 형식의 **할당 연산자(=)**로 값을 담습니다.

```python
name = "kyle"
age = 20
is_male = True
```

> 수학의 등호(=)와 달리 "같다"가 아니라, **오른쪽 값을 왼쪽 변수에 대입**한다는 뜻입니다.

## 변수의 장점

1. **데이터에 의미를 부여한다** — `20`은 그 자체로는 나이인지 개수인지 알 수 없지만, `age = 20`이라고 하면 명확해진다.
2. **재사용성과 가독성을 높인다** — 같은 문자열을 여러 번 출력할 때 변수 하나로 재사용 가능.
3. **유지보수를 쉽게 한다** — 값을 한 곳(변수 선언부)만 고치면 이를 참조하는 모든 코드에 반영된다.

## 식별자와 리터럴

- **식별자(Identifier)**: 변수의 이름 (할당 연산자 왼쪽)
- **리터럴(Literal)**: 데이터의 값 (할당 연산자 오른쪽)

> 변수는 **상자**, 식별자는 상자에 붙은 **이름**, 리터럴은 상자에 담긴 **값**.

**변수명 작성 규칙**

1. 알파벳, 언더바(`_`), 숫자로 구성 (예: `number`, `my_note`, `car1`)
2. 첫 글자에 숫자 불가 (`1car` 불가능)
3. 대소문자 구별 (`a`와 `A`는 다른 변수)
4. 띄어쓰기 대신 언더바로 구분 (`my_list`)
5. 예약어로 지을 수 없음

**예약어**: `False`, `None`, `True`, `and`, `as`, `assert`, `async`, `await`, `break`, `class`, `continue`, `def`, `del`, `elif`, `else`, `except`, `finally`, `for`, `from`, `global`, `if`, `import`, `in`, `is`, `lambda`, `nonlocal`, `not`, `or`, `pass`, `raise`, `return`, `try`, `while`, `with`, `yield`

## 재할당과 동시 할당

변수는 **가장 마지막으로 할당한 값**만 기억한다(재할당).

```python
number = 100
number = 200
number = 300
print(number)  # 300
```

여러 변수에 한 줄로 값을 할당할 수도 있다.

```python
x = y = 10       # 동일한 값 할당 → x=10, y=10
x, y = 10, 20    # 서로 다른 값 동시 할당 → x=10, y=20
```
