# 반복문(Loop)

같은 동작을 여러 번 반복해야 할 때(예: 0부터 99까지 출력), 반복문을 쓰면 100줄의 `print` 대신 2줄로 줄일 수 있다.

```python
for i in range(100):
    print(i)
```

## for 문 — 반복 횟수가 정해진 경우

`range(start, end, step)`으로 연속된 정수 목록을 만들어 함께 쓴다. `start`는 생략 시 0, `end`는 포함되지 않는다.

```python
range(1, 11)      # 1, 2, ..., 10
range(1, 11, 2)   # 1, 3, 5, 7, 9
range(10, 0, -1)  # 10, 9, ..., 1 (음수 step은 역방향)
range(5)          # 0, 1, 2, 3, 4 (start 생략)
```

```python
for i in range(5):         # 반복 가능한 자료형에서 값을 하나씩 꺼내 변수에 할당
    print(i)

for i in range(1, 6):      # 조건문과 결합 → 필터링
    if i % 2 == 0:
        print(i)           # 짝수만 출력
```

## while 문 — 반복 횟수가 정해지지 않은 경우

**초기화 → 조건문 → (반복 동작) → 증감식** 구조가 반드시 필요하다.

```python
i = 0            # 초기화
while i <= 4:     # 조건 (참이면 반복, 거짓이면 종료)
    print(i)
    i += 1        # 증감식 — 없으면 무한루프(INFINITE LOOP) 발생
```

> 조건에 쓰는 변수를 초기화하지 않으면 에러가 나고, 증감식이 없어 조건이 계속 참이면 **무한루프**가 된다.

## break와 continue

두 키워드 모두 `for`/`while` 양쪽에서 사용 가능하며, 보통 조건문과 함께 쓴다.

- **`break`**: 반복문을 즉시 종료한다.
- **`continue`**: 아래 코드를 건너뛰고 다음 반복으로 넘어간다 (일종의 필터링).

```python
for i in range(1, 11):
    print(i)
    if i == 3:
        break              # i가 3이면 반복 종료

for i in range(1, 21):
    if i % 2 == 0:
        continue           # 2의 배수면 건너뜀
    if i % 3 == 0:
        continue           # 3의 배수면 건너뜀
    print(i)                # 2의 배수도 3의 배수도 아닌 수만 출력
```

> **주의**: 같은 들여쓰기 레벨에서 `break`/`continue` 아래에 있는 코드는 실행되지 않는다.
