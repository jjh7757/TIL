# 클래스 상속(Inheritance)

상속은 이미 있는 클래스(부모)의 속성과 메서드를 새 클래스(자식)가 그대로 물려받고, 필요한 부분만 새로 정의하는 방법이다.

## 기본 상속과 메서드 오버라이딩

```python
class Person:
    def __init__(self, name):
        self.name = name

    def walk(self):
        print(f"{self.name}이 걷습니다.")

class Student(Person):        # Person을 상속
    def study(self):          # 자식 고유 메서드
        print(f"{self.name}이 학습을 수행합니다.")

    def walk(self):            # 부모 메서드를 덮어씀(오버라이딩)
        print("나는 걷습니다.")

s = Student("김철수")
s.walk()    # "나는 걷습니다." — 자식의 walk가 우선
s.study()   # 부모에는 없는, 자식만의 메서드
```

`Student`는 `__init__`을 따로 정의하지 않았으므로 `Person`의 `__init__`을 그대로 물려받아 `self.name`이 정상적으로 설정된다. `walk`처럼 자식 클래스에서 같은 이름의 메서드를 다시 정의하면 부모의 것을 덮어쓴다(오버라이딩).

## `super()` — 부모의 기능을 재사용하기

자식 클래스에서 부모의 로직을 완전히 대체하지 않고 "부모가 하던 것 + 추가 동작"으로 확장하고 싶을 때, `super()`로 부모의 메서드를 호출한다.

```python
class Person:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        print(f"제 이름은 {self.name}입니다.")

class Developer(Person):
    def __init__(self, name, language):
        super().__init__(name)      # 부모 생성자 재사용 — name 초기화 로직 중복 없이
        self.language = language

    def introduce(self):
        super().introduce()          # 부모 메서드를 먼저 실행하고
        print(f"주력 언어는 {self.language}입니다.")   # 이어서 자식만의 동작 추가

dev = Developer("이영희", "Python")
dev.introduce()
# 제 이름은 이영희입니다.
# 주력 언어는 Python입니다.
```

`super().__init__(name)`이 없다면 `Developer`의 생성자에서 `self.name`을 다시 직접 대입해야 해서, `Person`의 초기화 로직이 부모/자식 두 군데에 중복된다.

## 같은 부모를 상속받는 여러 자식

같은 부모를 상속받는 자식들은 각자 다른 방식으로 부모 메서드를 오버라이딩해서 "공통 동작 + 각자의 차이"를 표현할 수 있다. 예를 들어 `Electronics`를 상속받는 `Smartphone`, `Fan`이 각각 `power_on`을 오버라이딩하면서도, `super().power_on()`으로 "전원이 켜진다"는 공통 동작 자체는 그대로 재사용하는 식이다.

## 다중 상속

파이썬 클래스는 부모를 여러 개 지정할 수도 있다.

```python
class Speaker:
    def play_sound(self):
        print("소리를 출력합니다.")

class Camera:
    def take_photo(self):
        print("사진을 촬영합니다.")

class SmartDevice(Speaker, Camera):   # 두 부모를 동시에 상속
    pass

device = SmartDevice()
device.play_sound()   # Speaker로부터 상속
device.take_photo()   # Camera로부터 상속
```

이렇게 만든 자식 클래스는 부모들의 메서드를 모두 물려받아 사용할 수 있다.
