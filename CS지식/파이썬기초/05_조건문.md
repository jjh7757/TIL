# 조건문(Condition)

## if / else

```python
if 조건문:
    조건문이 참일 때 실행
else:
    조건문이 거짓일 때 실행
```

- 조건문 끝에는 반드시 콜론(`:`)을 붙인다.
- 조건문은 [비교·논리 연산자](03_연산자.md)로 만들어지며 `True`/`False`로 평가된다.

## 들여쓰기(Indentation)

파이썬은 코드 블록을 들여쓰기(4 spaces)로 구분한다. `if`/`else`에 속한 동작은 반드시 들여써야 하며, 들여쓰지 않은 코드는 조건과 무관하게 항상 실행된다.

```python
if True:
    print("조건이 참입니다.")
else:
    print("조건이 거짓입니다.")

print("무조건 실행됩니다.")  # if/else 밖 → 항상 실행
```

## 중첩 조건문 vs elif

여러 조건을 나눠야 할 때 `if` 안에 `if`를 중첩할 수도 있지만, 들여쓰기가 깊어져 가독성이 떨어진다. 이럴 때 `elif`(else if의 줄임)를 사용한다.

**중첩으로 작성** (age가 30 이상/20 이상/20 미만 분기):

```python
if age >= 30:
    print("30대입니다.")
else:
    if age >= 20:
        print("20대입니다.")
    else:
        print("미성년자입니다.")
```

**elif로 개선** — 같은 로직을 한 단계 들여쓰기로 표현:

```python
if age >= 30:
    print("30대입니다.")
elif age >= 20:
    print("20대입니다.")
else:
    print("미성년자입니다.")
```

`elif`는 여러 번 이어 붙여 조건을 계속 추가할 수 있다.

```python
if age >= 30:
    print("30대입니다.")
elif age >= 20:
    print("20대입니다.")
elif age >= 10:
    print("10대입니다.")
else:
    print("응애입니다.")
```

> **독립된 `if`를 여러 개 쓰는 것과 `elif`로 잇는 것은 다르다.** 독립된 `if`는 각 조건을 모두 검사해 여러 개가 동시에 실행될 수 있지만, `elif` 체인은 먼저 만족한 조건 하나만 실행되고 나머지는 검사하지 않는다. 아래 두 코드를 비교하면 차이가 드러난다.

```python
money = 15000
# 독립된 if 3개 — 각각 검사되므로 조건이 겹치면 여러 줄이 출력될 수 있음
if money >= 20000:
    print('치킨')
if money >= 10000:
    print('라면')   # 15000은 10000 이상이므로 이것도 출력됨
if money >= 1000:
    print('과자')   # 이것도 출력됨

# elif 체인 — 먼저 만족하는 조건 하나만 실행
if money >= 20000:
    print('치킨')
elif money >= 10000:
    print('라면')   # 이 줄만 실행되고 아래는 검사하지 않음
elif money >= 1000:
    print('과자')
else:
    print('집밥')
```
