# 집합(Set)과 튜플(Tuple)

## 집합(Set)이란

집합은 0개 이상의 원소를 **중복 없이, 순서 없이** 저장하는 컨테이너다. 중괄호(`{}`)로 생성하고, [리스트](06_리스트.md)와 함께 변경 가능한(mutable) 컨테이너로 분류된다.

```python
numbers = {10, 20, 30, 40, 50}
print(numbers)          # 순서를 보장하지 않음에 주의
print({1, 1, 1, 1})     # {1} — 중복은 자동 제거
```

**원소 제약**: 집합의 원소로는 기본 자료형과 변경 불가능한 컨테이너(정수·실수·문자열·불린·튜플·레인지)만 허용된다. 리스트·집합·딕셔너리 같은 변경 가능한 컨테이너는 원소가 될 수 없다(`TypeError`).

```python
data = {[1, 2]}   # TypeError: unhashable type: 'list'
```

> **빈 집합 주의**: `{}`는 집합이 아니라 **빈 딕셔너리**로 취급된다. 빈 집합은 반드시 `set()`으로 만든다.

## 집합 연산 — 교집합·합집합·차집합

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a & b)   # {3}       — 교집합: 공통 원소
print(a | b)   # {1,2,3,4,5} — 합집합: 모든 원소(중복 제거)
print(a - b)   # {1, 2}    — 차집합: a에만 있는 원소
```

## 멤버십 연산과 반복

리스트와 마찬가지로 `in`/`not in`을 지원한다. 다만 **인덱스가 없으므로** 원소를 직접 꺼내서만 반복할 수 있고, 순서가 없어 반복 순서가 항상 같다는 보장이 없다.

```python
numbers = {1, 2, 3}
print(1 in numbers)   # True

for number in numbers:
    print(number)
```

## 자주 쓰는 집합 메서드

| 메서드 | 역할 |
|---|---|
| `add(값)` | 원소 1개 삽입 (이미 있으면 변화 없음) |
| `update(컨테이너)` | 컨테이너의 모든 원소를 한꺼번에 삽입 |
| `remove(값)` | 원소 삭제, **없으면 `KeyError`** |
| `discard(값)` | 원소 삭제, 없어도 에러 없음 |

> `remove`와 `discard`의 차이만 기억하면 된다 — 존재 보장이 안 되는 값을 지울 땐 `discard`가 안전하다.

## 튜플(Tuple)

튜플은 **변경 불가능한(immutable) 리스트**라고 이해하면 된다. 소괄호(`()`)로 생성하며, 인덱싱으로 조회는 되지만 수정은 안 된다.

```python
t = (1, 2, 3)
print(t[1])   # 2 — 조회는 가능

t[2] = 3      # TypeError — 리스트와 달리 수정 불가
```

리스트 대신 튜플을 쓰는 대표적인 이유는 "이 데이터는 이후 절대 바뀌면 안 된다"는 의도를 코드로 표현하기 위해서다.
