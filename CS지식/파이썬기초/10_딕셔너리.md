# 딕셔너리(Dictionary)

딕셔너리는 **키(key)-밸류(value) 쌍**을 순서 없이 저장하는 컨테이너다. 중괄호(`{}`) 안에 `key: value` 형태로 콤마(`,`)로 구분해 작성한다.

```python
students = {"kyle": 10, "alex": 20}
print(students)
print(type(students))
```

## 키의 제약과 중복

- **키**는 [집합](09_집합과튜플.md#집합set이란)의 원소와 같은 규칙을 따른다 — 기본 자료형과 변경 불가능한 컨테이너만 가능하고, 리스트 등 변경 가능한 컨테이너는 키가 될 수 없다(`TypeError`). **밸류는 어떤 자료형이든 가능하다.**
- 키는 중복을 허용하지 않는다. 같은 키를 다시 넣으면 **나중 값으로 덮어씌워진다.**

```python
students = {"kyle": 10, "kyle": 20}
print(students)   # {'kyle': 20}
```

> **빈 딕셔너리**는 `{}`로 만든다 (빈 집합은 `set()`이어야 하는 것과 반대).

## 형변환 — `dict()`

키-밸류로 매핑될 수 있는 형태(튜플의 리스트 등)라면 `dict()`로 변환할 수 있다.

```python
student_list = [("kyle", 10), ("alex", 20)]
print(dict(student_list))   # {'kyle': 10, 'alex': 20}
```

## 삽입·수정·조회·삭제

```python
students = {}
students["kyle"] = 10   # 삽입
students["kyle"] = 20   # 수정 (같은 문법)

print(students["kyle"])        # 조회 — 없는 키면 KeyError
print(students.get("kyle"))    # get은 없어도 에러 없이 None(또는 기본값) 반환
print(students.get("없는것", 0))  # 0
```

## 멤버십 연산

`in`/`not in`은 **키(key)의 포함 여부**를 확인한다 (밸류가 아니다).

```python
students = {"kyle": 10, "alex": 20}
print("kyle" in students)   # True
```

## 자주 쓰는 메서드

| 메서드 | 역할 |
|---|---|
| `get(키)` / `get(키, 기본값)` | 없는 키를 조회해도 에러 대신 `None`(또는 지정한 기본값) 반환 |
| `pop(키)` / `pop(키, 기본값)` | 해당 키-밸류 쌍을 제거하고 그 밸류를 반환 |
| `keys()` | 모든 키 목록 |
| `values()` | 모든 밸류 목록 |
| `items()` | 모든 (키, 밸류) 쌍 목록 |

## 반복

`for`로 딕셔너리를 그냥 반복하면 **키**가 나온다. 밸류나 (키, 밸류) 쌍을 원하면 `.values()`/`.items()`를 쓴다.

```python
students = {"kyle": 10, "alex": 20}

for name in students:                # 키 반복 (기본값)
    print(name)

for age in students.values():        # 밸류 반복
    print(age)

for name, age in students.items():   # 키·밸류 동시 반복
    print(f"{name}의 나이는 {age}")
```

## 여러 사람의 정보를 표현하기 — 딕셔너리 리스트

값 여러 개를 각각 리스트로 따로 관리하는 것보다, **딕셔너리를 원소로 담은 리스트**가 "사람 한 명 = 하나의 묶음"이라는 구조를 더 명확히 드러낸다.

```python
# 덜 명확함: 이름/나이가 같은 인덱스로만 연결되어 있음을 암묵적으로 가정해야 함
names = ["alex", "ken", "kyle"]
ages = [16, 18, 17]

# 더 명확함: 각 사람의 정보가 하나의 딕셔너리로 묶여 있음
people = [
    {"name": "alex", "age": 16},
    {"name": "ken", "age": 18},
    {"name": "kyle", "age": 17},
]

for person in people:
    print(person["name"])
```
