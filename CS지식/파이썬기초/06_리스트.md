# 리스트(List)

## 컨테이너(Container) 자료형

하나의 변수엔 하나의 값만 담을 수 있어, 값이 여러 개(사람 100명의 이름 등)면 변수를 여러 개 만들어야 하는 한계가 있다. 컨테이너는 **여러 데이터를 한 곳에 저장**하는 자료형으로 이 문제를 해결한다.

**순서에 따른 분류**

- **순서 있음(Sequence)**: 리스트, 문자열, 레인지, 튜플 — 데이터를 연속된 공간에 순서대로 저장
- **순서 없음(Non-sequence)**: 집합, 딕셔너리

> "순서가 있다"와 "정렬되어 있다"는 다르다. `[1, 5, 2, 6]`은 정렬되어 있지 않지만 1→5→2→6 순서로 저장되어 있으므로 순서는 있다.

**변경 가능성에 따른 분류**

- **변경 가능(Mutable)**: 리스트, 집합, 딕셔너리 — 생성 후 삽입/수정/삭제 가능
- **변경 불가능(Immutable)**: 문자열, 레인지, 튜플

`id()` 내장함수로 객체의 고유값(주소)을 보면 차이가 드러난다. 리스트는 `append` 등으로 값을 바꿔도 `id()`가 유지되지만(내부만 변경), 튜플은 `+=`로 값을 바꾼 것처럼 보여도 실제로는 **새로운 객체가 재할당**되어 `id()`가 달라진다.

## 리스트란

대괄호(`[]`)로 생성하고 각 원소는 콤마로 구분한다. 다양한 자료형을 섞어 담을 수 있고, 빈 리스트(`[]`)도 가능하다.

```python
numbers = [10, 20, 30, 40, 50]
data = [10, 1.5, "python", False]  # 자료형 혼합 가능
print(len(numbers))                # 5, 길이
print(list((10, 20, 30)))          # 튜플 → 리스트로 형변환
```

## 리스트 연산

```python
a = [1, 2]; b = [3, 4]
print(a + b)      # [1, 2, 3, 4] — 리스트 합치기
print([1, 2] * 3) # [1, 2, 1, 2, 1, 2] — 원소 반복
print([1] * 10)   # 같은 값 10개짜리 리스트를 만들 때 유용
```

## 인덱싱 / 슬라이싱

인덱스는 **0부터** 시작하며, 음수 인덱스는 뒤에서부터(마지막이 `-1`).

```python
numbers = [10, 20, 30, 40, 50]
print(numbers[0], numbers[-1])   # 10 50
numbers[1] = -1                  # 인덱스로 원소 수정
```

슬라이싱은 `리스트[start:end:step]` — `end`는 포함되지 않는다.

```python
numbers = [10, 20, 30, 40, 50]
print(numbers[2:4])    # [30, 40]
print(numbers[1:4:2])  # [20, 40]      — step 간격으로 자르기
print(numbers[:3])     # [10, 20, 30]  — start 생략 시 처음부터
print(numbers[2:])     # [30, 40, 50]  — end 생략 시 끝까지
print(numbers[::-1])   # 리스트 뒤집기
```

## 멤버십 연산자 (`in` / `not in`)

원소가 리스트에 있는지 판별해 `True`/`False`를 반환한다. [조건문](05_조건문.md)과 자주 함께 쓰인다.

```python
classroom = ["kyle", "alex", "justin"]
if "alex" in classroom:
    print("alex는 출석했습니다.")
```

## 반복

```python
names = ["kyle", "alex", "justin"]

for name in names:               # 리스트를 직접 반복 (가장 일반적)
    print(name)

for i, name in enumerate(names): # (인덱스, 원소) 쌍으로 반복
    print(i, name)
```

## 삽입과 삭제

```python
a = [10, 20, 30, 40, 50]
a.append(60)   # 맨 끝에 삽입 → [10, 20, 30, 40, 50, 60]
a.pop()        # 맨 끝 원소 삭제(반환값으로 받을 수 있음)
a.pop(2)       # 특정 인덱스 원소 삭제
```

## 리스트 컴프리헨션

`[표현식 for 변수 in 리스트]` 형식으로 반복문 없이 리스트를 만든다.

```python
numbers = [i for i in range(1, 11)]
even_numbers = [i for i in range(1, 11) if i % 2 == 0]  # 조건으로 필터링
```

## 자주 쓰는 메서드

| 메서드 | 역할 |
|---|---|
| `insert(idx, val)` | 특정 인덱스에 원소 삽입 |
| `extend(iterable)` | 리스트 끝에 다른 리스트를 이어 붙임 |
| `remove(val)` | 해당 값을 가진 첫 원소 삭제 |
| `count(val)` | 해당 값의 개수 반환 |
| `index(val)` | 해당 값의 인덱스 반환 (없으면 `ValueError`) |
| `sort()` / `sort(reverse=True)` | 오름차순 / 내림차순 정렬 |
| `reverse()` | 순서를 그대로 뒤집음 |
