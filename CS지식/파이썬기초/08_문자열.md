# 문자열(String)

문자열은 0개 이상의 문자를 순서 있게 저장하는 컨테이너 자료형이다. 작은따옴표(`'`) 또는 큰따옴표(`"`)로 생성하며, 빈 문자열·원소 1개짜리 문자열·공백도 모두 문자열이다.

```python
sentence = "hello python"
print(len(sentence))        # 12 (공백 포함)
print(str([10, 20, 30]))    # "[10, 20, 30]" — 다른 컨테이너를 문자열로 형변환
```

## 문자열 연산

```python
a = "hello"; b = "python"
print(a + b)     # "hellopython" — 덧셈으로 합치기
print("안녕" * 3) # "안녕안녕안녕" — 곱셈으로 반복
```

## 인덱싱과 수정 불가

리스트처럼 인덱싱·슬라이싱이 되지만, 문자열은 [변경 불가능한(immutable) 컨테이너](06_리스트.md)라 인덱스로 직접 수정할 수 없다.

```python
word = "python"
print(word[1], word[-1])   # y n

word[0] = "j"   # TypeError — 문자열은 수정 불가

new_word = "j" + word[1:]  # 덧셈+슬라이싱으로 "수정한 것처럼" 보이는 새 문자열 생성
print(new_word)             # "jython" — word 자체는 그대로다
```

**슬라이싱**은 리스트와 동일하게 `문자열[start:end:step]`.

```python
s = "abcdefghi"
print(s[2:5])    # cde
print(s[::-1])   # ihgfedcba — 문자열 뒤집기
```

## 멤버십 연산과 반복

```python
sentence = "hello"
print("h" in sentence, "j" not in sentence)  # True True

for char in sentence:               # 직접 반복
    print(char)

for i, char in enumerate(sentence): # (인덱스, 문자) 쌍으로 반복
    print(f"index: {i}, char: {char}")
```

## 문자열 포매팅

| 방식 | 예시 | 비고 |
|---|---|---|
| 덧셈 | `"제 이름은 " + name + " 입니다."` | 타입이 섞이면 별도 `str()` 변환 필요 |
| f-string | `f"{name}은 {age}살 입니다."` | 중괄호 안에 연산·함수 호출도 가능(`f"{age + 1}살"`). 가장 많이 씀 |
| `.format` | `"{subject}에 대해서 알려줘.".format(subject="아이유")` | f-string보다 예전 문법이지만, LLM 프롬프트 템플릿 작성 시 여전히 자주 쓰임 |

## 자주 쓰는 문자열 메서드

| 메서드 | 역할 | 예시 |
|---|---|---|
| `split(구분자)` | 구분자 기준으로 나눠 리스트 반환 (구분자 생략 시 공백 기준) | `"hello$python".split("$")` → `['hello', 'python']` |
| `strip()` / `lstrip()` / `rstrip()` | 양쪽 / 왼쪽 / 오른쪽의 특정 문자(기본은 공백) 제거 | `" hello ".strip()` → `"hello"` |
| `find(값)` / `index(값)` | 값의 인덱스 반환 | `find`는 없으면 `-1`, `index`는 없으면 `ValueError` |
| `count(값)` | 값의 개수 반환 | `"hello".count("l")` → `2` |
| `replace(old, new)` | 문자열 치환 (원본 유지, 새 문자열 반환) | `"hello".replace("h", "j")` → `"jello"` |
| `join(컨테이너)` | 컨테이너의 원소들을 구분자로 이어붙임 | `" ".join(["hello", "python"])` → `"hello python"` |

## 아스키코드(ASCII)

- **bit**: 0과 1을 나타내는 최소 단위. **byte**: 8bit(256가지 표현, 저장의 기본 단위)
- 아스키코드는 영문 알파벳을 숫자로 표현하는 표준 규칙이며, 문자 1개당 1byte를 쓴다.

```python
print(ord("A"))   # 65 — 문자 → 아스키코드
print(chr(65))    # "A" — 아스키코드 → 문자
```
