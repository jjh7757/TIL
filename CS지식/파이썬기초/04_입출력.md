# 입력(input)과 출력(print)

## 입력 — `input()`

값을 소스 코드에 직접 써두면 실행할 때마다 다른 값을 받을 수 없다. `input()` 내장함수를 쓰면 프로그램 실행 중 터미널에서 사용자 입력을 받을 수 있다.

```python
name = input("이름을 입력하세요: ")  # 괄호 안 문구는 입력 안내 문구
print(name)
```

> **주의**: `input()`으로 받는 값은 **항상 문자열**이다. 숫자로 쓰려면 명시적 형변환이 필요하다.

```python
age = input()          # "20" (문자열)
age_int = int(age)     # 20 (정수)
print(type(age_int))   # <class 'int'>
```

## 출력 — `print()`

기본적으로 괄호 안 값을 출력하고 줄바꿈한다. `print()`만 쓰면 빈 줄만 출력된다.

**여러 값 출력** — 콤마(`,`)로 구분하면 기본적으로 공백을 기준으로 출력된다.

```python
print("hello", "python", "yeah!")  # hello python yeah!
```

**`end` 옵션** — 출력 끝에 줄바꿈 대신 지정한 문자를 붙인다 (기본값은 `"\n"`).

```python
print("Hello World", end="!")
print("안녕하세요")
# Hello World!안녕하세요
```

**`sep` 옵션** — 여러 값을 출력할 때 구분자를 공백 대신 지정한다.

```python
print("Hello", "World", sep="$")   # Hello$World
print("hello", "python", sep="\n") # 줄바꿈으로 구분해 세로로 출력
```
