# 함수(Function)

함수는 **입력(input)을 넣으면 어떤 출력(output)을 반환하는 블랙박스**다. 내부에서 어떻게 처리하는지 몰라도, 특정 입력에는 원하는 결과가 나올 것이라 기대하고 쓴다. 프로그램 안의 미니 프로그램이라고도 볼 수 있다.

## 함수의 구조

```python
def 함수명(매개변수):
    함수에서 실행되는 동작
    return 반환값
```

- `def` 키워드 + 함수명 + 매개변수, 끝에 콜론(`:`)
- 함수명(식별자) 규칙은 [변수명 규칙](01_변수.md#식별자와-리터럴)과 동일하다.
- 매개변수가 함수의 **입력**, `return`이 함수의 **출력**에 해당한다.

## 함수를 쓰는 이유

동일한 로직이 여러 곳에 반복되면 코드가 길어지고, 로직을 고칠 때마다 모든 곳을 손봐야 한다.

```python
# 함수 없이 — 같은 if/else가 중복됨
a, b = 5, 10
if a > b:
    bigger1 = a
else:
    bigger1 = b

c, d = 6, 3
if c > d:
    bigger2 = c
else:
    bigger2 = d

# 함수로 — 로직은 한 곳에만 존재
def get_bigger(x, y):
    if x > y:
        return x
    else:
        return y

bigger1 = get_bigger(a, b)
bigger2 = get_bigger(c, d)
```

[변수의 장점](01_변수.md#변수의-장점)과 같은 맥락 — **재사용성 · 가독성 · 유지보수**.

## 선언과 호출, 용어 정리

- **선언(define)**: `def`로 함수를 작성하는 것
- **호출(call)**: `함수명(인자)`로 실행하는 것
- **매개변수(parameter)** vs **인자(argument)**: 매개변수는 함수를 정의할 때 받는 변수, 인자는 호출할 때 실제로 넘기는 값

```python
def add(x, y):   # x, y가 매개변수
    return x + y

result = add(1, 2)   # 1, 2가 인자
```

> **내장함수 vs 메서드**: 내장함수(`len()`, `print()` 등)는 파이썬에 기본 내장된 함수이고, 메서드(`리스트.append()` 등)는 특정 자료형에 종속된 함수다. 모든 메서드는 함수이지만, 모든 함수가 메서드는 아니다.

## 자주 쓰는 내장함수

| 함수 | 역할 | 예시 |
|---|---|---|
| `abs(x)` | 절댓값 | `abs(-2.5)` → `2.5` |
| `sum(리스트)` | 합계 | `sum([1,2,3,4])` → `10` |
| `min(리스트)` / `max(리스트)` | 최소·최대값 | |
| `sorted(리스트, reverse=True)` | 정렬된 **새 리스트** 반환 (원본 불변) | `sorted([5,2,-1,0])` → `[-1,0,2,5]` |
| `map(함수, 리스트)` | 각 원소에 함수를 적용한 결과(map 객체, `list()`로 감싸야 눈에 보임) | `list(map(int, ["1","2","3"]))` → `[1,2,3]` |

## 매개변수·반환값 유무에 따른 4가지 형태

| 매개변수 | 반환값 | 예시 |
|:---:|:---:|---|
| O | O | `def add(x, y): return x + y` |
| O | X | `def hello(name): print(f"Hello! {name}!")` |
| X | O | `def even_numbers(): return [i for i in range(1, 11) if i % 2 == 0]` |
| X | X | `def welcome(): print("Welcome!")` |

반환값이 없는 함수는 호출 결과를 변수에 담아도 `None`이 담긴다는 점을 알아두면 실수를 줄일 수 있다.

## 정렬·최댓값 기준 지정 — `key`와 람다

`max`, `min`, `sorted`처럼 값을 서로 비교해야 하는 함수는 `key` 인자로 "무엇을 기준으로 비교할지"를 함수로 넘겨줄 수 있다. 딕셔너리 리스트처럼 값 자체를 바로 비교할 수 없는 데이터에 특히 유용하다.

```python
movies = [
    {"title": "A", "vote_average": 7.8},
    {"title": "B", "vote_average": 8.9},
]

def get_vote_average(movie):
    return movie["vote_average"]

best = max(movies, key=get_vote_average)   # key에는 함수 그 자체(호출하지 않은 상태)를 넘긴다
print(best["title"])   # B
```

이렇게 한 번만 쓰고 버릴 짧은 함수는 `def`로 이름 붙여 선언하는 대신, **람다(lambda)**라는 이름 없는 함수로 바로 넘기는 경우가 많다.

```python
# lambda 매개변수 : 반환값
best = max(movies, key=lambda movie: movie["vote_average"])

sorted_movies = sorted(movies, key=lambda movie: movie["vote_average"], reverse=True)

# 즉시 호출도 가능하다
print((lambda x: x * 2)(3))   # 6
```

람다는 표현식 하나만 담을 수 있어 `if`/`for` 같은 문장을 여러 줄 쓸 수 없다. 로직이 복잡해지면 이름 있는 함수로 분리하는 편이 낫다.

## 함수 호출 흐름 — 콜스택(Call Stack)

함수가 서로를 호출하면, 파이썬은 "누가 누구를 호출했고 어디로 돌아가야 하는지"를 스택 구조로 관리한다. 함수를 **호출하면 스택에 쌓이고(push)**, 함수가 **끝나 return하면 스택에서 빠진다(pop)**.

```python
def func1():
    print(1)

def func0():
    print(5)
    func1()
    print(0)

def func3():
    print(4)
    func0()
    print(3)

func3()
```

실행 순서는 `4 → 5 → 1 → 0 → 3`이다. `func3` 안에서 `func0`을 호출하면 `func3`은 그 줄에서 잠시 멈추고 콜스택 맨 위에 `func0`이 쌓이며, `func0`이 끝나야(`pop`) `func3`이 멈췄던 지점(`print(3)`)부터 이어서 실행된다. 에러가 발생했을 때 보게 되는 traceback도 이 콜스택을 그대로 위에서 아래로 보여주는 것이다.
