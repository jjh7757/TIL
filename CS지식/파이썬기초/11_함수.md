# 함수(Function)

함수는 **입력(input)을 넣으면 어떤 출력(output)을 반환하는 블랙박스**다. 내부에서 어떻게 처리하는지 몰라도, 특정 입력에는 원하는 결과가 나올 것이라 기대하고 쓴다. 프로그램 안의 미니 프로그램이라고도 볼 수 있다.

## 함수의 구조

```python
def 함수명(매개변수):
    함수에서 실행되는 동작
    return 반환값
```

- `def` 키워드 + 함수명 + 매개변수, 끝에 콜론(`:`)
- 함수명(식별자) 규칙은 [변수명 규칙](01_변수.md#식별자와-리터럴)과 동일하다.
- 매개변수가 함수의 **입력**, `return`이 함수의 **출력**에 해당한다.

## 함수를 쓰는 이유

동일한 로직이 여러 곳에 반복되면 코드가 길어지고, 로직을 고칠 때마다 모든 곳을 손봐야 한다.

```python
# 함수 없이 — 같은 if/else가 중복됨
a, b = 5, 10
if a > b:
    bigger1 = a
else:
    bigger1 = b

c, d = 6, 3
if c > d:
    bigger2 = c
else:
    bigger2 = d

# 함수로 — 로직은 한 곳에만 존재
def get_bigger(x, y):
    if x > y:
        return x
    else:
        return y

bigger1 = get_bigger(a, b)
bigger2 = get_bigger(c, d)
```

[변수의 장점](01_변수.md#변수의-장점)과 같은 맥락 — **재사용성 · 가독성 · 유지보수**.

## 선언과 호출, 용어 정리

- **선언(define)**: `def`로 함수를 작성하는 것
- **호출(call)**: `함수명(인자)`로 실행하는 것
- **매개변수(parameter)** vs **인자(argument)**: 매개변수는 함수를 정의할 때 받는 변수, 인자는 호출할 때 실제로 넘기는 값

```python
def add(x, y):   # x, y가 매개변수
    return x + y

result = add(1, 2)   # 1, 2가 인자
```

> **내장함수 vs 메서드**: 내장함수(`len()`, `print()` 등)는 파이썬에 기본 내장된 함수이고, 메서드(`리스트.append()` 등)는 특정 자료형에 종속된 함수다. 모든 메서드는 함수이지만, 모든 함수가 메서드는 아니다.

## 자주 쓰는 내장함수

| 함수 | 역할 | 예시 |
|---|---|---|
| `abs(x)` | 절댓값 | `abs(-2.5)` → `2.5` |
| `sum(리스트)` | 합계 | `sum([1,2,3,4])` → `10` |
| `min(리스트)` / `max(리스트)` | 최소·최대값 | |
| `sorted(리스트, reverse=True)` | 정렬된 **새 리스트** 반환 (원본 불변) | `sorted([5,2,-1,0])` → `[-1,0,2,5]` |
| `map(함수, 리스트)` | 각 원소에 함수를 적용한 결과(map 객체, `list()`로 감싸야 눈에 보임) | `list(map(int, ["1","2","3"]))` → `[1,2,3]` |

## 매개변수·반환값 유무에 따른 4가지 형태

| 매개변수 | 반환값 | 예시 |
|:---:|:---:|---|
| O | O | `def add(x, y): return x + y` |
| O | X | `def hello(name): print(f"Hello! {name}!")` |
| X | O | `def even_numbers(): return [i for i in range(1, 11) if i % 2 == 0]` |
| X | X | `def welcome(): print("Welcome!")` |

반환값이 없는 함수는 호출 결과를 변수에 담아도 `None`이 담긴다는 점을 알아두면 실수를 줄일 수 있다.
