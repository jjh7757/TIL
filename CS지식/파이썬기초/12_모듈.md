# 모듈(Module)

모듈은 특정 기능을 하는 코드를 파이썬 파일(`.py`) 단위로 묶어놓은 것이다. 모듈을 쓰면 다른 파일에 작성된 [함수](11_함수.md)를 새로 짜지 않고 가져다 쓸 수 있고, 기능 단위로 코드가 분리돼 유지보수가 쉬워진다.

## import

```python
# module.py 파일에 아래처럼 정의돼 있다고 가정
# def add(x, y):
#     return x + y

import module
print(module.add(1, 2))   # 모듈이름.함수명 형식으로 사용
```

모듈 이름 없이 함수만 바로 쓰고 싶다면 `from 모듈이름 import 함수명` 형식을 쓴다.

```python
from module import add
print(add(1, 2))   # 모듈명 없이 바로 사용 가능
```

## 자주 쓰는 표준 모듈

파이썬은 다양한 표준 모듈을 기본 제공해서, 웬만한 기능은 직접 구현하지 않고 불러와 쓸 수 있다.

### math — 수학 연산

```python
import math

math.sqrt(2)     # 제곱근
math.pow(2, 3)   # 거듭제곱 (2의 3제곱)
math.ceil(3.2)   # 올림 → 4
math.floor(3.8)  # 내림 → 3
math.pi          # 원주율
```

### random — 난수

```python
import random

random.randint(1, 5)          # 1~5 사이 정수 1개 (끝값 포함)
random.choice([10, 20, 30])   # 리스트 원소 중 1개 무작위 선택
random.sample([10, 20, 30, 40, 50], 3)  # 지정 개수만큼 무작위 추출(중복 없이)
```

### collections — 특수 컨테이너

```python
from collections import Counter, defaultdict

# Counter: 원소별 개수를 세어줌
counter = Counter([1, 2, 2, 3, 4, 4, 4])
counter[4]              # 3
counter.most_common()   # 빈도 높은 순으로 정렬된 (원소, 개수) 목록

# defaultdict: 존재하지 않는 키를 조회하면 KeyError 대신 기본값으로 자동 초기화
students = defaultdict(list)
students["names"].append("kyle")   # 키가 없어도 에러 없이 빈 리스트가 자동 생성됨
```

### itertools — 순열·조합

```python
from itertools import permutations, combinations

numbers = [1, 2, 3]

list(permutations(numbers, 2))   # 순열 — 순서 다르면 다른 경우로 취급: (1,2),(2,1),(1,3)...
list(combinations(numbers, 2))   # 조합 — 순서 상관없이 뽑기: (1,2),(1,3),(2,3)
```

> 순열과 조합의 차이만 기억하면 된다 — **순서를 구분하는가**의 여부다.
