# 반응형 웹과 모바일 퍼스트

화면 크기가 제각각인 여러 기기(PC, 태블릿, 모바일)에 하나의 웹사이트를 대응시키는 두 가지 접근 방식이다.

## 반응형 웹 (Responsive Web Design)

하나의 HTML/CSS 코드가 화면 크기(뷰포트)를 감지해서 레이아웃을 유동적으로 바꾸는 방식. 기기별로 별도 사이트를 만들지 않아도 된다.

- **미디어 쿼리(Media Query)**: CSS에서 화면 너비 등 조건에 따라 다른 스타일을 적용
  ```css
  .container { width: 100%; }

  @media (min-width: 768px) {
    .container { width: 750px; }
  }
  ```
- **뷰포트(Viewport) 메타 태그**: 모바일 브라우저가 PC용 화면을 축소해서 보여주지 않고, 기기 화면 너비 그대로 렌더링하게 함
  ```html
  <meta name="viewport" content="width=device-width, initial-scale=1">
  ```
- **유동 그리드/이미지**: 요소 크기를 px 대신 `%`, `rem`, `flex`, `grid` 등 상대 단위로 잡아 화면이 늘어나고 줄어들어도 깨지지 않게 함

## 모바일 퍼스트 (Mobile First)

반응형 웹을 **만드는 순서**에 대한 전략. PC 화면을 먼저 설계하고 모바일에 맞춰 줄이는(Desktop First) 대신, **모바일 화면을 기준으로 먼저 설계**한 뒤 화면이 커질수록 요소를 추가하는 방식.

- CSS도 이 순서를 따라 `min-width` 미디어 쿼리로 작성한다 (화면이 **커질 때** 스타일 추가)
  ```css
  /* 기본값 = 모바일 */
  .menu { display: none; }

  @media (min-width: 1024px) {
    .menu { display: flex; } /* PC에서만 노출 */
  }
  ```
- **왜 모바일을 기준으로 잡는가**
  - 실제 웹 트래픽에서 모바일 접속 비중이 PC보다 높은 경우가 많음
  - 구글 검색엔진이 **모바일 화면 기준으로 색인(Mobile-First Indexing)** 하기 때문에 SEO에도 유리
  - 좁은 화면에서 핵심 콘텐츠·기능만 남기고 설계하면, 화면이 커질 때 살을 붙이는 게 반대 방향(PC에서 덜어내기)보다 자연스러움

## 반응형 웹 vs 모바일 퍼스트

| 구분 | 반응형 웹 | 모바일 퍼스트 |
|------|-----------|----------------|
| 성격 | 화면 크기에 **대응하는 기술**(미디어 쿼리 등) | 무엇을 **기준으로 먼저 설계**할지에 대한 **전략** |
| 기준 화면 | 기기 상관없이 동일 코드 | 모바일을 기본값으로 두고 확장 |
| 미디어 쿼리 방향 | `max-width`(PC 기준, 작아지면 축소)도 가능 | `min-width`(모바일 기준, 커지면 확장)를 주로 사용 |

즉 모바일 퍼스트는 반응형 웹을 구현하는 여러 방법 중, "모바일을 기본값으로 놓고 위로 확장한다"는 설계 우선순위에 대한 이야기다.
