# 환경변수와 `.env` 관리

API 키, 토큰, 비밀번호 같은 값을 코드에 직접 적으면 그 코드를 커밋하는 순간 깃허브에 그대로 노출된다. **환경변수**는 이런 값을 코드 밖(실행 환경)에 두고, 코드에서는 이름으로만 참조하게 해서 이 문제를 피하는 방법이다.

## `.env` 파일 + `python-dotenv`

로컬 개발에서는 프로젝트 루트에 `.env` 파일을 두고 `KEY=값` 형식으로 값을 적어둔 뒤, `python-dotenv` 라이브러리로 이 파일을 읽어 환경변수로 등록한다.

```bash
pip install python-dotenv
```

```
# .env
TMDB_TOKEN=abcd1234...
DEBUG=True
PORT=8000
```

```python
import os
from dotenv import load_dotenv

load_dotenv()   # .env 파일의 내용을 현재 프로세스의 환경변수로 로드

token = os.getenv("TMDB_TOKEN")
debug_mode = os.getenv("DEBUG")
port = os.getenv("PORT")
```

`os.getenv("이름")`은 해당 환경변수가 없으면 에러 대신 `None`을 반환한다.

## `.env`는 절대 커밋하지 않는다

`.env`는 실제 비밀값이 들어있으므로 `.gitignore`에 등록해 커밋 대상에서 제외한다. 대신 **어떤 키가 필요한지**만 값 없이 적어둔 `.env.example`을 커밋해서, 다른 사람이 프로젝트를 받았을 때 무엇을 채워 넣어야 하는지 알 수 있게 한다.

```
# .env.example — 값은 비워두고 키 이름만 공유
TMDB_TOKEN=
TMDB_API_KEY=
```
