# 컴퓨터 구조

수업 중 손글씨 판서를 정리한 내용입니다.

## 하드웨어 구성 요소

```
컴퓨터 구조
 ├─ CPU (중앙처리장치)
 ├─ MB (마더보드)
 ├─ RAM (주 메모리)
 └─ SSD / HDD (보조기억장치)
```

- **CPU (중앙처리장치)**: 명령어를 해석하고 실제 연산을 처리
- **MB (마더보드)**: CPU, RAM 등 부품들을 서로 연결해주는 기판
- **RAM (주 메모리)**: 실행 중인 프로그램이 올라가는 공간
  - 속도가 빠름
  - **휘발성**: 전원이 꺼지면 저장된 내용이 사라짐
- **SSD / HDD (보조기억장치)**: 전원이 꺼져도 데이터가 유지되는 비휘발성 저장장치. 프로그램은 평소 여기에 저장돼 있다가 실행될 때 RAM으로 올라감

## 운영체제 (OS)
CPU, RAM, 보조기억장치 같은 하드웨어 자원과 그 위에서 돌아가는 프로그램 사이를 관리하는 소프트웨어.

## 프로그램 → 프로세스 → 스레드
- **프로그램**: 보조기억장치(SSD/HDD)에 저장되어 있는 정적인 파일
- **프로세스**: 프로그램이 실행되어 RAM에 올라간 상태 (실행 중인 프로그램)
- **멀티스레드**: 하나의 프로세스 안에서 여러 작업을 동시에 처리하는 방식

## 정리
프로그램은 보조기억장치에 저장되어 있다가 실행되면 RAM에 올라가 프로세스가 되고, 그 프로세스 안에서 멀티스레드로 여러 작업을 동시에 처리한다. 이 흐름 전체는 CPU가 연산을 수행하고 운영체제가 자원을 관리하며, 마더보드가 부품들을 물리적으로 연결해준 위에서 이뤄진다.

> 판서 일부 글씨(RAM 오른쪽의 초록색 메모 등)는 판독이 어려워 이번 정리에서는 생략했습니다.
