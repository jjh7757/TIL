# 소량 데이터 GPU 미세조정: 입력 조건, 재확인, 결과 파일 관리

[소량 데이터 이미지 회귀: 실험을 운영하는 법](소량데이터_이미지회귀_실험운영.md)에서는 사전학습 모델의 가중치를 고정하고 선형 회귀를 얹는 방식을 다뤘다. 이 글은 그다음 단계, 클라우드 GPU에서 사전학습 ViT를 직접 미세조정하면서 배운 것들이다. 하루 동안 가장 큰 개선은 새 모델이 아니라 **학습 입력 조건 하나**에서 나왔고, 가장 큰 손실은 모델이 아니라 **결과 파일과 세션 관리**에서 나왔다.

## 1. 크롭 증강은 "정답이 국소적일 때"만 안전하다

무작위 크롭은 이미지 증강의 기본이라 별생각 없이 이미지의 일부(예: 면적의 70~80%)만 잘라 학습했다. 그런데 크롭을 **이미지 전체에 가깝게** 키웠더니 모든 시드에서 크게 좋아졌다.

이유는 정답이 무엇으로 정해지는지에 있다.

| 정답의 성격 | 예 | 크롭 증강 |
|---|---|---|
| 국소적 (물체가 어딘가에 있음) | 분류, 검출 | 일부를 잘라도 정답 유지 → 안전 |
| 전역 통계 (이미지 전체의 평균·분포) | 재질 물성, 밀도, 비율 | 일부만 보면 정답이 달라짐 → **라벨 잡음** |

- 정답이 이미지 전체의 통계로 정해진다면, 일부만 잘라 보여 주는 건 "다른 이미지에 같은 정답"을 붙이는 것과 비슷하다.
- 게다가 예측은 전체(또는 중앙의 큰 영역)로 했으니 **학습 조건과 예측 조건도 어긋나 있었다.**
- 해결은 간단하다. 크롭을 이미지 전체에 가깝게(위치 이동 몇 픽셀 정도만) 하고, 학습과 예측의 입력 크기를 같게 맞춘다.

> 증강을 고를 때 "라벨을 바꾸지 않는가"를 데이터의 정답 정의에서부터 따져 볼 것. 회전·반전은 등방적인 이미지에서 안전했지만, 크롭은 정답 정의에 따라 위험할 수 있다.

## 2. 시드 하나의 개선은 의심부터

하이퍼파라미터 몇 개를 바꿔 시드 하나로 시험하면, 그중 하나는 우연히 좋아 보이기 마련이다. 실제로 "좋아 보였던" 설정이 다른 두 시드(다른 폴드 분할)에서 다시 돌리면 개선이 사라지는 일이 하루에 두 번 있었다.

```
후보 4개를 시드 1개로 시험 → 1개가 좋아 보임
→ 같은 설정을 다른 시드 2개로 재확인
→ 평균 내면 기존과 차이 없음 → 채택 안 함
```

- 여러 후보 중 가장 좋은 것을 고르는 순간 **선택 편향**이 생긴다. 고른 뒤에는 고를 때 쓰지 않은 데이터(다른 폴드 분할)로 다시 재야 한다.
- 반대로 진짜 효과(예: 위의 크롭 변경)는 모든 시드에서 같은 방향으로 나왔다. "모든 시드에서 같은 방향"이 가장 믿을 만한 신호였다.

## 3. 같은 모델, 다른 해상도 = 값싼 다양성

입력을 2배로 키워(업샘플링) 같은 모델을 학습하면, 단독 점수는 원래 해상도와 비슷하거나 약간 나빴다. 그런데도 앙상블에 넣으면 좋아졌다.

- 해상도가 다르면 패치 하나가 보는 영역이 달라져서, 모델이 **다르게 틀린다**(잔차 상관이 1보다 충분히 낮음).
- 반면 구조가 완전히 다른 모델(CNN)은 다르게 틀리긴 했지만 너무 약해서 앙상블을 오히려 망쳤다.
- 정리하면 앙상블 후보의 조건은 **"충분히 강하면서 다른가"**다. 같은 강한 모델의 입력 조건을 바꾸는 게 가장 값싸게 이 조건을 맞추는 방법이었다.

## 4. 앙상블 비중을 데이터로 고르면 과적합한다

계열별 비중을 OOF 예측에 맞춰(음수 아닌 최소제곱) 학습하면 OOF 점수는 좋아진다. 하지만 그 **선택 절차 자체를 교차검증**(바깥 폴드로 비중을 고르고 안쪽 폴드에서 평가)해 보니 고정 균등 비중보다 나빴다.

| 방식 | 평가 |
|---|---|
| 전체 OOF로 비중 학습 | 가장 좋아 보임 (낙관적, 같은 데이터로 고르고 평가) |
| 비중 학습을 중첩 교차검증 | **고정 균등보다 나쁨** |
| 고정 균등 비중 | 기준 |

- 수백 장 데이터로 5개 비중을 맞추면, 비중이 데이터의 우연을 따라간다.
- 비중을 바꾸고 싶다면 "OOF가 좋아졌다"가 아니라 "선택 절차를 교차검증해도 좋아졌다"를 확인해야 한다. 같은 방법으로 큰 그룹 두 개의 비중(예: 50% → 75%)은 통과했고, 계열별 세밀한 비중은 실패했다.

## 5. 폴드 모델 평균 vs 전체 데이터 재학습

교차검증의 각 폴드 모델은 데이터의 80%로만 학습된다. test 예측을 폴드 모델 평균으로만 하면 나머지 20%를 버리는 셈이다.

- 학습 곡선(데이터 양에 따른 CV)을 그려 보면 데이터가 늘수록 아직 좋아지는 구간이었다.
- 그래서 **같은 설정·같은 에포크로 전체 데이터 재학습**한 예측을 폴드 평균 예측과 함께 섞었다. 리더보드에서 두 번 모두 작게나마 좋아졌다.
- 단, 전체 재학습 모델은 검증 데이터가 없어서 CV로 평가할 수 없다. 설정은 CV로 검증된 것을 그대로 쓰고, 에포크 같은 조기 종료 기준은 바꾸지 않는다.

## 6. 결과 파일은 "설정이 이름에 다 들어가게"

하루에 결과 파일을 두 번 덮어썼다. 둘 다 모델 문제가 아니라 관리 문제였다.

1. **파일 이름에 설정이 빠짐**: 크롭 크기를 바꿨는데 이름에는 크롭이 없어서 새 결과가 기존 결과를 덮어씀.
2. **같은 세션의 결과 폴더가 누적됨**: 클라우드 노트북 세션을 이어 쓰다 보니 폴더에 남아 있던 옛 파일이 압축 파일에 다시 섞여, 복구한 원본을 또 덮어씀.

그래서 바꾼 규칙:

```python
# 기본값과 다른 설정은 전부 이름에 붙인다
TAG = base_name \
    + (f"_crop{crop}" if crop != 224 else "") \
    + (f"_bs{bs}" if bs != 16 else "") \
    + (f"_x{scale:g}" if scale != 1 else "")   # ... 학습률, EMA, 노이즈 등도
```

- 실험마다 **새 결과 폴더**를 쓰고, 압축은 그 폴더만 한다.
- 일부 폴드만 돌릴 때(나머지는 빈 값으로 저장됨)는 반드시 다른 폴더에 저장한다.
- 결과를 받으면 **기록해 둔 점수와 파일에서 다시 계산한 점수를 대조**한다. 덮어쓰기를 가장 빨리 잡는 방법이다.
- 원본 압축 파일은 지우지 않는다. 두 번 다 그걸로 복구했다.

## 7. 클라우드 노트북에서 장시간 학습 버티기

브라우저 연결이 끊긴 뒤 새로고침했더니, 재연결 과정에서 커널에 인터럽트가 들어갔고 **노트북이 띄운 학습 하위 프로세스까지 같이 죽었다.** 같은 프로세스 그룹이라 신호가 함께 전달된 것이다.

살린 것과 바꾼 것:

- **폴드마다 저장**해 두었기 때문에 끝난 폴드는 남아 있었다. 남은 폴드만 다시 돌려 합쳤다.
- 폴드별 난수 시드를 `seed * 10 + fold`처럼 **폴드 번호로 고정**해 두었기 때문에, 따로 돌린 폴드도 한 번에 돌린 것과 같은 조건이었다.
- 노트북 구조를 바꿨다.

```python
# 학습을 커널과 다른 세션으로 띄움 → 커널 인터럽트·재연결 신호가 전달되지 않게
subprocess.Popen(cmd, shell=True, stdout=open(log, "w"), stderr=subprocess.STDOUT,
                 env=env, start_new_session=True)
```

| 셀 | 역할 |
|---|---|
| 실행 | 학습을 백그라운드로 띄우고 바로 끝남. 이미 돌고 있으면 실행 거부 |
| 진행 표시 | 로그 파일만 읽어 1분마다 출력. 언제든 중단·재실행 가능 |
| 결과 묶기 | 이번 실험 폴더만 압축 |

- 진행 표시를 학습과 분리하니, 화면이 멈춰도 "진행 표시만 다시 실행"하면 된다.
- 세션 자체를 끄면(작업 디렉터리가 사라지는 경우) 이 방법으로도 못 살린다. 결과는 중간중간 내려받아 둔다.
- 개편 후 첫 장시간 학습은 끊김 없이 끝났다. 다만 "연결이 끊겨도 정말 살아남는지"는 아직 실제로 겪어 보지 않아서, 원리상 그렇다는 수준이다.

## 정리

- 크롭·리사이즈 같은 증강은 **정답이 어떻게 정의되는지**부터 보고 고른다. 전역 통계가 정답이면 이미지 전체를 보여 준다.
- 시드 하나의 개선은 다른 시드로 재확인하기 전까지 믿지 않는다.
- 앙상블은 "강하면서 다른" 모델로. 같은 모델의 입력 해상도만 바꿔도 다양성이 생긴다.
- 비중은 고정이 기본, 바꾸려면 선택 절차까지 교차검증.
- 전체 데이터 재학습 예측을 함께 쓰면 버리던 데이터를 활용할 수 있다.
- 결과 파일 이름에 설정을 전부 넣고, 실험마다 새 폴더, 받으면 대조.
- 장시간 학습은 커널과 분리하고, 폴드마다 저장하고, 폴드 시드를 고정한다.
