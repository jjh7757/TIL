# AI 리터러시 & LLM 애플리케이션 입문

## LLM이란
- 지금까지의 글 다음에 올 토큰을, 확률적으로 예측하는 기계
## 토큰이란
- LLM이 글을 처리하는 최소 단위
- 토큰의 고정된 크기의 단위가 아니라 모델의 토크나이저가 의미와 사용 빈도를 고려해 가변적으로 나누는 텍스트 처리 단위이다
- 영어보다 한국어가 좀 더 비싸다
## LLM 학습 과정
1. 사전학습
- 방대한 텍스트 데이터를 이용하여 다음 토큰 예측을 무수히 시도해 언어, 지식, 추론 패턴을 학습
2. 지도 미세조정(SFT)
- 지시에 대한 모범답안을 학습시켜 지시를 따르는 능력을 향상
3. 인간 피드백 강화학습(RLHF)
- 사람이 답변에 순위를 매기고, 선호되는 답변 스타일을 강화

## LLM의 동작 원리(토큰, 다음 토큰 예측, 학습 3단계)를 비전공자에게 5분 안에 설명
```text
LLM은 텍스트를 **토큰(Token)**이라는 단위로 나누어 처리하며, 지금까지 입력된 토큰을 바탕으로 다음에 올 토큰을 하나씩 예측하여 문장을 생성하는 모델입니다.

이러한 LLM을 만들기 위해서는 먼저 방대한 양의 텍스트 데이터를 이용해 다음 토큰을 예측하는 과정을 반복하며 언어의 패턴과 지식을 학습하는 **사전학습(Pre-training)**을 수행합니다. 이후 질문과 그에 대한 모범 답안을 학습시켜 사용자의 지시를 더 정확하게 이해하고 따르도록 하는 **지도 미세조정(Supervised Fine-Tuning, SFT)**을 진행합니다. 마지막으로 RLHF(Reinforcement Learning from Human Feedback) 또는 **DPO(Direct Preference Optimization)**와 같은 선호도 학습을 통해 사람의 기대와 선호에 맞는 답변을 생성하도록 모델을 조정합니다.
```
## LLM 한계
1. 환각
- 모르는 정보를 그럴듯한 거짓말로 대답하는 현상
2. 지식 컷오프
- 학습이 끝난 시점 이후의 일에 대해 옛날 데이터로만 이용해서 대답하는 현상
3. 컨텍스트 윈도우
- 모델이 기억할 수 있는 토큰의 총량
4. 비결정성
- 같은 질문에 다른 대답이 나오는 현상
- 같은 형식의 대답을 원하면 프롬프트로 형식을 강하게 고정하거나 API의 온도 설정을 낮춘다

## 좋은 프롬프트의 4요소 :: 역할 - 맥락 - 작업 - 형식
1. 역할
- 누구로서 답해야 하는지 명시한다
2. 맥락
- 어떤 상황, 배경인지 명시한다
3. 작업
- 무엇을 해야하는지 정학히 명시한다
4. 형식
- 결과물의 형식을 명시한다
