# 미니프로젝트 아이디어 초안

오늘 만든 KIS 모의투자 텔레그램 봇([금융투자봇 TIL](../n8n실습/금융투자봇/README.md))을
"질문에 답하는 봇"에서 "먼저 알아채고 알려주는 어드바이저"로 확장한 최종 아이디어.

## 프로젝트명
KIS 모의투자 연동 AI 투자 어드바이저 봇 — 리스크 관리 확장판

## 오늘 만든 것 (Base)
- 시세조회 / 잔고조회 / 모의 매수·매도 (사용자 승인 후에만 실행)
- KIS 토큰 캐싱, Supabase에 거래 기록

## 확장 아이디어

### 1. 가격 알림 (Proactive Alert)
"삼성전자 8만원 넘으면 알려줘" → `alerts` 테이블에 등록하고, 스케줄 워크플로우(5~10분 주기)가
조건을 확인해서 충족되면 봇이 먼저 말을 건다.

### 2. 포트폴리오 리스크 경고
- 특정 종목 비중이 목표치(예: 30%)를 넘으면 "집중 리스크" 경고
- 계좌 평가손익이 일정 % 이상 하락하면 경고 알림
- 단순 조회 봇과 가장 크게 차별화되는 지점 — 금융권이 중요하게 보는 "리스크 관리" 로직을 직접 설계

### 3. 거래내역 조회 tool
"내 거래내역 보여줘" → `trade_log`를 조회해서 자연어로 요약 답변

### 4. 매일 아침 계좌 요약 리포트 (스케줄)
장 시작 전(예: 08:50) 보유종목 현재가·등락률·총평가금액을 정리해서 먼저 보내주는 모닝 브리핑.
질문을 기다리는 게 아니라 능동적으로 정보를 제공하는 에이전트라는 점을 보여줌.

## 이번 확장에서 다루지 않는 것
- 뉴스·공시 감성분석 (범위가 크고 정확도 검증이 어려움 — 추후 아이디어로만 남김)
- 실제 자금이 오가는 진짜 매매
- 여러 계좌/다중 사용자 지원

## 포트폴리오 차별점
- 스프레드시트가 아니라 실제 증권사 Open API와 연동
- 주문 전 사용자 승인을 강제하는 안전장치 설계
- 리스크 경고 로직(집중도, 손익 임계치)을 직접 설계 — 단순 챗봇이 아니라 금융 실무에 맞닿은 에이전트
- 스케줄 기반 자동화(알림, 아침 리포트)까지 포함해 다양한 트리거 방식을 활용

## 다음에 만들 순서 (우선순위)

2. 가격 알림 등록 tool + 체커 스케줄
3. 포트폴리오 리스크 경고 로직
4. 아침 요약 리포트 스케줄
