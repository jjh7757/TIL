# 프로젝트 도구와 Obsidian 활용
## Obsidian, Notion, Jira, GitHub의 역할을 구분
| 도구 | 주된 목적 | 수업에서 사용하는 내용 |
|------|-----------|----------------------|
| Obsidian | 개인 학습과 생각 연결 | 수업 노트, 기준선(Baseline), 용어집, 질문 관리 |
| Notion | 팀 문서 공유와 협업 | 회의록, 결정 사항, 일정 공유 |
| FigJam | 자유로운 아이디어와 흐름 탐색 | 도메인 요소와 아키텍처 초안 |
| Mermaid | 텍스트 기반 다이어그램 작성 | 업무 흐름, 데이터 흐름, 아키텍처 다이어그램 |
| Figma | 정돈된 화면 및 시각 자료 제작 | 최종 아키텍처, 발표 자료 |
| Jira | 개발 작업 및 진행 상태 관리 | 작업(Task), 담당자, 일정, 상태 확인 |
| GitHub | 코드와 문서의 버전 관리 | Commit, Branch, Pull Request, 문서(docs) 관리 |
| VS Code | 코드와 Markdown 문서 편집 | 프로젝트 파일 및 Markdown 작성 |
| 생성형 AI | 초안 작성 및 검토 지원 | 구조 검토, 용어 불일치 확인, 누락 내용 검토 |

-도구 연결 흐름

``` text
Obsidian에서 개인 생각과 수업 내용을 정리합니다.
→ FigJam에서 도메인과 흐름을 자유롭게 배치합니다.
→ Mermaid로 구조화된 다이어그램을 작성합니다.
→ 생성형 AI로 빠진 요소를 검토합니다.
→ Figma에서 발표용 결과를 수정합니다.
→ Notion에서 팀과 결정 내용을 공유합니다.
→ 현업에서는 Jira와 같은 도구에서 실행 작업과 진행 상태를 관리합니다.
→ GitHub에서 코드와 문서를 버전 관리합니다
```

## Obsidian이란
-Markdown 파일을 기반으로 개인 지식과 프로젝트 문서를 연결해 관리하는 노트 도구
-Vault는 Obsidian에서 md파일 여러개를 저장하는 작업 폴더를 말한다
-[[문서이름]]로 문서간 내부 링크를 만들 수 있다. [[문서이름#부제이름]]으로 링크를 타고 부제이름위치로 이동시킬 수 있다

## Mermaid란
- 텍스트 기반으로 다양한 다이어그램을 생성할 수 있도록 도와주는 아주 편리한 툴
