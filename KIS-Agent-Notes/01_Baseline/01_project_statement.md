## 프로젝트명

KIS 모의투자 연동 텔레그램 AI 에이전트

---

## 프로젝트 한 문장

```
모의투자를 처음 시작하는 초보 투자자가
투자용어와 계좌 화면을 해석하지 못해 매매 판단을 내리지 못하는 문제를
KIS 모의투자 계좌 데이터와 용어 설명을 결합한 텔레그램 대화로 줄여
모의 매매 1건마다 자신의 판단 근거를 스스로 적고 설명할 수 있도록 합니다.
```

### 문장 구조 확인

| 요소 | 내용 |
|---|---|
| 누가 | 모의투자를 처음 시작하는 초보 투자자 |
| 어떤 문제 | 투자용어와 계좌 화면을 해석하지 못해 매매 판단을 내리지 못한다 |
| 어떻게 | KIS 모의투자 계좌 데이터 + 용어 설명을 텔레그램 대화로 제공 |
| 어디까지 | 모의 매매 1건마다 자신의 판단 근거를 스스로 적고 설명할 수 있는 상태 |

---

## 성공 기준

**사용자가 자신의 매매 판단 근거를 설명할 수 있는가.**

### 왜 "수익"을 성공 기준으로 쓰지 않았습니까?

프로젝트 초기에는 성공 기준을 `모의투자로 안정적인 수익을 낸다`로 검토했습니다. 다음 이유로 제외했습니다.

| 문제 | 설명 |
|---|---|
| 통제 불가 | 시장이 하락하면 시스템이 완벽하게 동작해도 수익은 나지 않습니다. 팀의 노력과 결과가 연결되지 않습니다. |
| 기간 내 검증 불가 | `안정적`이라는 표현은 최소 수개월의 데이터를 요구합니다. 5일 프로젝트의 발표일에 확인할 수 없습니다. |
| 문제와 층위 불일치 | 이 프로젝트가 정의한 문제는 `용어를 이해하지 못한다`(이해의 문제)입니다. 수익은 성과의 문제이므로 문제와 목표가 연결되지 않습니다. (교안 4.6) |
| 설계 왜곡 | 수익을 목표로 걸면 시스템이 종목 추천기 방향으로 끌려가고, 특정 종목 매수 권유는 유사투자자문 영역에 해당하는 위험이 발생합니다. |

**수익은 `장기 기대 효과`로 내려둡니다.** 이 프로젝트에서는 측정하지 않습니다.

### 측정 방법

| 측정 항목 | 확인 방법 |
|---|---|
| 근거 기록률 | 완료된 모의 매매 중 판단 근거가 함께 저장된 건의 비율 |
| 용어 재질문 감소 | 같은 사용자가 동일한 용어를 다시 묻는 횟수의 변화 |
| 근거 설명 가능성 | 매매 후 "왜 이 종목을 골랐습니까?"에 사용자가 답할 수 있는지 직접 확인 |

## 확인한 사실

| 사실 | 근거 |
|---|---|
| KIS Open API로 모의투자 계좌의 토큰 발급·자동 갱신이 동작한다 | **본인이 n8n으로 구현하여 동작 확인** |
| KIS Open API로 계정·잔고 조회가 동작한다 | 동일 |
| KIS Open API로 시세·종목정보 조회가 동작한다 | 동일 |
| KIS Open API로 주문 실행과 주문·체결 조회가 동작한다 | 동일 |
| 텔레그램 봇으로 메시지 수·발신이 동작한다 | 동일 |
| LLM 호출이 동작한다 | 동일 |
| 데이터 저장소에 기록을 쌓을 수 있다 | 동일 |

> 위 7개는 **추정이 아니라 이미 동작을 확인한 사실**입니다. 따라서 이 프로젝트의 남은 과제는 개별 기능의 구현이 아니라 **기능 사이의 연계**입니다.

## 확인이 필요한 가정

교안 4.4에 따라 사실과 가정을 구분합니다. 아래는 **아직 확인하지 않은 가정**입니다.

| 가정 | 검증 방법 |
|---|---|
| 초보 투자자가 매매를 못 하는 주된 이유는 용어를 모르기 때문이다 | 초보 투자자 3명 이상에게 "왜 매매를 망설였는가"를 직접 질문 |
| 용어와 계좌 상황을 설명해주면 매매 근거를 스스로 말할 수 있게 된다 | 설명 제공 전후로 사용자가 근거를 말할 수 있는지 비교 |
| 주문 시점에 근거 입력을 요구해도 사용자가 이탈하지 않는다 | 근거 입력 단계에서의 이탈 여부 확인 |
| 초보 투자자는 텔레그램을 투자 도구로 쓰는 데 거부감이 없다 | 대상 사용자에게 선호 채널 질문 |
| 모의투자 사용자는 실제 투자와 같은 방식으로 판단한다 | 모의투자 경험자에게 실제 투자와의 차이 질문 |

> 5일 일정에서는 위 가정을 전부 검증할 수 없습니다. **첫 두 개만 최소 인원으로 확인하고, 나머지는 미검증 가정으로 명시한 채 진행**합니다. 가정을 감추지 않는 것이 교안 4.4의 요구입니다.
