# API 실습 — 간단 사주 보기 (saju.html)

## 개요
이름·생년월일·태어난 시간·성별을 입력받아 백엔드 API(`/api/saju`)에 POST로 넘기고, 그 응답을 그대로 화면에 보여주는 프론트엔드 실습 페이지입니다.

## 파일 구조
- `saju.html` — 폼 UI + fetch 호출 로직만 있는 단일 HTML 파일 (별도 CSS/JS 파일 없음)

## 동작 방식
1. 이름, 생년월일, 태어난 시간(선택), 성별을 입력받는다.
2. 제출 시 `fetch('/api/saju', { method: 'POST', body: JSON.stringify(payload) })`로 입력값을 그대로 서버에 전달한다.
3. 서버 응답(`data.result`)을 결과 박스에 그대로 출력한다. 실패하면 에러 메시지를 보여준다.

## 미완성 부분
- 사주팔자를 실제로 계산하는 로직은 없다. 입력값을 그대로 서버로 던져서 Gemini 같은 LLM이 알아서 해석하게 하는 임시 구조 (코드 내 TODO 주석 참고).
- `/api/saju` 백엔드 엔드포인트는 이 폴더에 포함되어 있지 않다 — 이 파일은 프론트엔드 단독으로는 동작하지 않고, 해당 엔드포인트를 제공하는 서버가 별도로 필요하다.
