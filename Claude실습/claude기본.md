# Claude 기본
## Chat vs Cowork vs Code
1. chat
- web에서 하는거랑 똑같음
- AI의 답변을 내가 복사하거나 다운로드해야됨
2. cowork
- AI가 내 pc조작가능(일반 사무업무에 더 가깝게 만들어줌)
3. code
- 내 pc조작가능(cowork보다 더 넓은 범위의 일 가능)

## AI가 내 pc조작
- 특정 폴더를 작업폴더로 지정하고 동작
- AI의 결과물이 내 작업폴더에 바로 저장됨


## AI 권한 옵션
1. 권한무시 옵션
- AI에게 권한 다줌
- 되돌릴수없는 작업에 대해서는 물어보는 경우도 있음
2. 편집자동수락
- 편집에대해서 승인요구 필요없음
3. 계획
- 계획만 세우고 변경에 대해 요구

## 클로드 작업탭 동그라미 설명
1. 왼쪽 작업 동그라미가 회색이다(작업중)
2. 노란색이다 (사용자가 결정해야 할 게 있다)
3. 하늘색이다(작업끝인데 아직 사용자가 확인안함)
4. 동그라미가 회색인데 안이 비었다(작업끝이고 확인도 함)
