- [x] 폼 생성

### 시트

- [x] 테스트 제출 1건 → 응답 시트에 행이 쌓이는지 확인

## 2단계 · 자동 트리거 (REQ-02) ⚠️ 선검증

**여기를 통과하기 전에 뒤 단계를 만들지 않는다.** 트리거를 마지막에 붙이면 전체를 다시 손대게 된다.

- [x] 워크플로우 신규 생성
- [x] `Google Sheets Trigger` 노드 추가
      - Credential: 1단계 OAuth
      - Document: 응답 스프레드시트
      - Sheet: `폼 응답1`
      - Event: `Row Added`
      - Poll Time: 1분
- [x] 워크플로우 **Active 로 전환** (비활성 상태면 트리거가 돌지 않는다)
- [x] 폼 제출 → **아무것도 누르지 않고** 대기
      → 확인: Executions 목록에 실행 이력이 자동 생성된다 (최대 1분 소요)
- [x] 실행 결과에서 4개 항목 값이 정상 수신되는지 확인
- [x] Manual Trigger 노드가 남아 있으면 삭제 또는 분리

> 1분 안에 안 돌면: Active 여부 → Sheet 이름 → Credential 권한 순으로 확인.

## 3단계 · 중복 방지 (REQ-03)

- [x] `Code` 노드: 정규화 + 중복키 생성
      - 이메일 소문자화 + 앞뒤 공백 제거
      - 물품번호 숫자만 추출
      - 문의유형 공백 제거
      - `중복키 = 이메일|물품번호|문의유형`
- [x] `Google Sheets (Get Rows)` 노드: `분석결과` 시트 조회, `Always Output Data` On
- [x] `Code` 노드: 조회된 행들과 `중복키` 비교 → `isDuplicate` boolean 계산
      (`$('정규화')` 참조 노드 이름 오류 수정 완료)
- [x] `IF` 노드: `isDuplicate == true` 판정
- [x] True 분기 → `NoOp` 노드로 **정상 종료** (저장·알림 없음)
- [ ] False 분기 → 이후 단계로 연결 (4단계에서 LLM 노드 붙이며 연결)
- [x] **노드 순서 점검: 중복 판정이 LLM 노드보다 앞에 있다** ← REQ-03 명시 조건
- [x] 같은 내용 2회 제출 → 2번째 실행이 True 분기로 빠지는지 확인
      → 확인: 실행은 성공(빨간 표시 아님), 시트 행은 늘지 않음

> `분석결과` 시트가 비어 있을 때(첫 문의)도 에러 없이 False 분기로 가는지 확인할 것.

## 4단계 · LLM 분류 (REQ-04)

- [x] `Basic LLM Chain` 노드 추가 (IF false 분기에 연결)
- [x] `Google Gemini Chat Model` 서브노드 연결, temperature `0`
- [x] `Structured Output Parser` 서브노드 연결, 5개 필드 스키마 정의
      `category / sentiment / urgency / summary / needs_review`
- [x] 프롬프트 입력 (기획서 REQ-04 초안)
- [x] **긴급도 판정 기준 3줄이 프롬프트에 들어갔는지 확인** ← 채점 항목
- [x] 입력에 `문의내용` 이 바인딩되는지 확인 (결제 오류 테스트로 확인됨)
- [x] 노드 설정: `Retry on Fail` 2회, `On Error = Continue` (문서 기준 1회보다 여유있게 설정)
- [ ] 분류 예시 5건(기획서 표)을 넣어 기대값과 맞는지 확인 → 8단계 통합 테스트에서 마무리
      → 확인: 환불 요구 → `상`, 사이즈 질문 → `하`

> **출력이 `output` 키로 한 단계 감싸져 나온다.** 뒤 노드에서는 `$json.category`가 아니라 `$json.output.category`로 참조해야 한다.

> 응답이 ` ```json ` 으로 감싸여 와도 여기서 고치지 말고 5단계 안전판이 처리하게 둔다.

## 진행 중 막혔을 때

| 증상 | 확인 순서 |
| --- | --- |
| 폼 제출해도 실행 안 됨 | 워크플로우 Active 여부 → Sheet 이름 → 1분 대기했는지 |
| 중복이 안 걸림 | `분석결과` 시트 `중복키` 열이 실제로 채워지는지 (6단계 누락이 원인인 경우가 많다) |
