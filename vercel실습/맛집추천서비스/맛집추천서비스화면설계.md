# 맛집 추천 서비스 화면 설계

[DB 설계](맛집추천서비스DB설계.md)의 `restaurants` 단일 테이블을 그대로 화면 3개에 매핑한다.

## 화면 3개

1. **목록** - 카드 그리드, 상단에 `가고 싶은 곳`(`visited = false`) / `다녀온 곳`(`visited = true`) 탭.
   탭 아래에 `예산 이하만 보기`(`budget` 필터)와 `카테고리`(한식/중식/일식/양식/카페) 필터.
   카드에는 이름·카테고리·예산, `다녀온 곳` 탭에서는 별점도 함께 표시.
   ![화면1 목록](../../image/vercel실습/맛집추천서비스/화면1.png)
2. **상세** - 식당 정보(이름·카테고리·주소·예산) + 별점(`rating`, 안 갔으면 빈 채로) + 메모(`memo`) +
   [수정] [삭제]. `다녀왔어요` 토글도 여기서 켜고 끔 (켜야 별점·메모 입력칸이 열림).
   ![화면2 상세](../../image/vercel실습/맛집추천서비스/화면2.png)
3. **등록** - 이름·카테고리·주소·예산 입력. `visited`는 기본값 false로 등록되고, 별점·메모는
   등록 화면에는 없음 (다녀온 뒤 상세 화면에서 채우는 정보라서).
   ![화면3 등록](../../image/vercel실습/맛집추천서비스/화면3.png)

## 화면 흐름

```
목록 ──(카드 탭)──▶ 상세 ──[수정]──▶ 등록 폼과 같은 입력 항목을 채운 채로 열림
  │                    └──[삭제]──▶ 목록으로 복귀
  └──(+ 버튼)──▶ 등록 ──(저장)──▶ 목록(가고 싶은 곳 탭)에 새 카드 추가
```

## DB 필드 ↔ 화면 매핑
| 화면 | 표시/입력 필드 | 비고 |
|---|---|---|
| 목록 | `name`, `category`, `budget`, `rating`(다녀온 곳만) | `visited`로 탭 구분, `budget`으로 필터 |
| 상세 | `name`, `category`, `address`, `budget`, `visited`, `rating`, `memo` | 전체 필드 표시·수정 |
| 등록 | `name`, `category`, `address`, `budget` | `visited`/`rating`/`memo`는 등록 시 입력 안 함 |
